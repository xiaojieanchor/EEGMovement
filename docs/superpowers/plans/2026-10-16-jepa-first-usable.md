# JEPA 首版训练与实时试用

用户要求：实际完成 JEPA 路线训练，先按个人记录的时间顺序输入，公开实测正确率、动静与方向概率，再提供试用。

1. 实现并测试空间掩码、可见上下文、停止梯度 EMA 教师、潜空间预测目标；继承官方权重并使用 8 倍 FFN（约 1825 万总参数）。
2. 固定公共训练分区、自监督训练预算和种子，保存逐轮指标、真实参数变化、不可变模型及源文件哈希。公共验证/锁定测试不参与拟合。
3. 个人原始会话连续因果滤波，断点重置，逐样本质量门控。短会话拟合，长会话验证；重叠窗口不跨试次或会话划分。验证后可用两组数据重拟合试用头，明确最终模型已见这些数据。
4. 通过独立服务器推理服务和 SSH 通道接入中枢，显示五类联合概率、动静概率、条件方向概率、来源、延迟、质量拒绝原因。过期结果清空，预测与实际 VR 执行分开。
5. 两组原始记录按时间顺序、实际节奏回放，记录每次推理和试次汇总。报告证据窗口、更新间隔、端到端返回延迟及准确率，不能用训练内回放冒充泛化。
6. 最终独立审阅和回归，提供模型路径、实测限制及试用入口。

验收：完成真实优化、有限概率且和为1、无目标泄漏/教师梯度、质量或时间断点拒绝；准确率必须如实报告。高正确率目标 80% 五类平衡准确率，仅用于评估，不作为承诺。数据不足不伪造通过。

裁定：工程不是 Git 仓库，使用源文件哈希与不可变运行目录留档，不初始化/迁移已有工程。首版训练先完成已验收且原生解析验证过的 D03 训练分区，不声称已训练全部401GB；其余公开数据需任务/质量/通道导入核验。当前授权允许实验试用，不能替代正式训练/闭环验收。
