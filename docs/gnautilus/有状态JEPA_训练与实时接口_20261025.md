# 联合导航有状态 JEPA：实际实现

本轮只采用联合导航任务：第一人称想象前后行走、左右转向，方向眼动提供辅助。真实佩戴与 Quest 动作验收已按用户安排延期；程序回归、录制回放和训练完成均不等于实机效果通过。

## 输入与来源

32路保持原始物理顺序。用户确认的映射位于 `configs/gnautilus_layout32_navigation_confirmed_20261025.json`：设备16=Cz、19=C5，SDK零基索引分别为15、18。其余位置沿用8个额部、21个运动区和3个顶区布局。

该确认不改写旧描述文件、不重排原始列、不改变原厂设备配置。REF/GND为32路之外的独立硬件接点，具体物理位置未记录，仍为未知。不能将公开 OpenBMI 的 nasion 参考写成本人参考。

数据仍只有“个人导航数据集”一个入口。三份NPZ原文件和完整试次划分保留：训练、验证、测试各5个试次，每类每集1个。旧稳定窗口数为2582／605／600，占68.18%／15.98%／15.84%；这是窗口数比例，不能写成试次数比例或独立样本数。

训练使用 `episode_eeg_uv` 及其偏移、任务标签和源样本位置，不把旧重叠窗口作为独立试验。头尾上下文保留，释放、准备及未标注位置保持UNKNOWN。任务锚点不是测得的脑内意图或扫视起点。

官方REST记录的高通为0.1Hz，软件记录为0.5Hz。两种原始合同仍分开记录；共同软件处理不构成原始来源等价。训练REST目前全部来自官方记录，是必须随结果展示的来源混杂。

## 编码器、公开资源与JEPA

`gnautilus_ml/stream_jepa.py` 实现两条单向有状态编码器：运动区24路、额部8路，每条包含时间卷积、空间卷积、4点池化和32维GRU。

- 运动分支用已有OpenBMI神经模型初始化时间层、按位置对应的20路空间层和GRU；FCz、P3、Pz、P4的新增空间权重从零开始。已有20路初始输出等价性有数值回归。
- 眼动辅助复用已有EOG神经模型的时间层及GRU；私人8路空间层重新适配。独立EOG电极没有被改名成头皮Fp／AF通道。
- OpenBMI、PhysioNet、非静止头位EOG保留原生任务头和教师；相同输入合同、类别和历史长度的经典分类器可参与软目标。公开手／脚、眼动任务不会被改成私人导航标签。
- 所有既有模型保留完整ID及权重哈希。实际使用及未纳入蒸馏的原因写入研究日志的 `reuse-inventory.json`，不能把多个不同任务的开发BA直接排序后当私人导航精度。

JEPA学生仅见当前及过去样本，预测两段未来潜表示：未来100–600ms、600–1100ms。每段未来原始支持独立处理，EMA目标不继承学生滤波或GRU状态。目标编码器和教师不执行在线动作推理。

真实采样支持逐更新保存在 `.supports.jsonl`。私人SSL候选池排除验证／测试试次及上下文，并留出2275样本保护范围；缺口、冲突和未通过32路粗筛的区域不进入该池。未标注记录不会因进入SSL而变成REST。

## 完整试次适配与治理

个人适配从每个完整试次开始顺序读取，跨段保留滤波和GRU状态。8秒只限定反向传播展开长度，段间只detach，不能把每个8秒片段从零状态开始。电气失效及真实段边界才重置。

有标签损失按每个试次的合格更新数归一化，每轮每个完整试次产生一次优化更新。长REST不会仅因持续时间长而被计作更多独立试次。有限历史对照单独训练，编码器在固定历史窗口重建，确认器仍保留自己的因果历史。

输出头学习率为0.001，解冻主干学习率为0.00003；先训练头及私人额部空间层，再小步适配主干。标准化只在允许的训练信号上拟合。模型选择、温度与门槛只用验证集；测试读取在 `selection-freeze.json` 提交之后，之后不重新拟合或选模。

`gnautilus.training_protocol.v2` 只用于明确的 `same_wearing_internal_research`。它没有关闭旧正式协议的分组、独立佩戴及最少试次数检查，也没有把该批数据标成跨佩戴验收通过。

检查点先写不可变载荷，再原子提交SHA指针。恢复时核对协议与载荷；CUDA映射加载后的随机状态必须先转CPU ByteTensor。已完成SSL阶段跨适配版本复用时，另核对原始输入、归一化、目标几何和SSL学习代码的语义指纹；不允许借此替换学习目标。导出阶段失败后从已冻结候选恢复，不重新接触测试反馈选模。

## 实时接口

运行时版本为 `gnautilus.causal_jepa_stream.v1`，旧有限历史模型继续兼容。中枢约每100ms发送新增的实际样本，首次预热可用已到达的真实历史；不能补零冒充历史。

`POST /inference/predict` 的有状态请求保留已有模型、generation、descriptor、stream_id、source_epoch字段，并增加：

```text
sample_index_start: 本次实际新增支持起点
sample_index_end: 本次实际新增支持终点（右开）
samples: 32 × T，原始物理顺序，单位uV，T=end-start
device_valid: 原厂有效性存在时逐新增支持检查；未测量保持未知
```

A100维护IIR、卷积缓存、池化余数和GRU状态。响应增加运动区分数、额部辅助分数、辅助状态、navigation_decision、warming和runtime_schema。UNKNOWN与REST分别返回，分数不称为真实意图概率。

完全相同的重发不推进确认，也不续推理证据租约；相同身份而内容变化拒绝并清状态。乱序、缺口、身份或模型变化重新预热。单次电气或设备无效清除模型状态；接触阻抗没有被粗筛指标冒充。

方向眼动一致时允许有限增益，但启动仍须运动区证据；回中或不确定使用更高门槛。返回瞬态先抑制反向，真正持续的新方向还须保守门槛及新的连续确认。默认3次新更新确认，2次证据不足停止。门槛来自冻结验证协议，旧实时滑块不能覆盖；推理与动作开关仍分别由用户控制。

中枢250ms输入新鲜度、Quest180ms动作票据、采集中暂停执行、失联停止和急停规则保留。100ms是更新节奏，不是首次意图响应或物理动作延迟承诺。

## 复现与结果

入口是 `scripts/navigation_jepa_admin.py`，使用本机已有凭据库及固定主机身份SSH访问指定A100。`upload`建立哈希清单，`deploy`先跑远端合成回归且要求服务空闲，`prepare`提交锁定研究协议，`start`创建持久任务，`status`读取实际事件，`download`收集回执。只有该私有模型服务进入真实训练权限上下文。

训练产物先完成安全NPZ导出、同设备输出一致性核对和模型库登记。其他候选及消融保存在研究日志，不创建额外私人数据标签。模型登记不自动开启推理或动作。

最终结果须并列报告原始分类BA、接纳覆盖、含拒识宏召回、明确REST误启动次数和观测时长，并区分开始、保持、回中／结束及中途启动。没有客观眼位真值，不报告虚构的扫视或回中识别率。真实方向切换、端到端动作延迟及新佩戴效果留待实机验收。
