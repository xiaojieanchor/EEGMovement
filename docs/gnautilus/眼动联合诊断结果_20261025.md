# 眼动辅助分类与32路联合导航：低准确率原因、优化和真实回放

2026年10月25日。技术结论范围：本次佩戴、既有训练／开发角色；不是独立测试或实机动作验收。

## 本轮结论

**发现并修正一处真实训练计权缺陷，同时完成了新增额部辅助分类器与全32路多时标读出的真实A100训练／推理。** 原眼动辅助损失对“方向只监督前2秒、REST监督全段”的不同支持长度，仍使用完整类别长度作权重分母，造成REST占86.21%的辅助损失权重。修正后每类占20%。但冻结原迁移编码器、仅改变计权方式的对照，眼动头开发BA仅19.31%→19.73%，所以这一错误不是低准确率的唯一解释。

相同643次合格开发更新上，原联合模型BA23.62%，新额部有符号多时标读出33.32%，全32路多时标读出34.79%，加入10%额部辅助为35.61%。**主要改善来自显式的时间／频带／跨通道特征，额部融合在该对照上仅增加约0.83个百分点。** 所有新增分类器仍有明显训练与开发落差；没有足够证据认定它们已适合控制。

本报告的“额部辅助分类器”使用前8路头皮信号和联合任务指令弱标签，不等于专用EOG电极分类器，也不等于测得真实眼位。没有给UNKNOWN、回中或眨眼编造真值。

## 眼动辅助原先没有提供有效方向增益

原额部方向头在开发643次合格更新上的BA为17.68%，最高类别分数的全段最大值仅约0.386，没有一次达到0.7方向辅助门槛。实际辅助状态为UNKNOWN592次、BLINK89次，没有ALIGNED方向增益。

BLINK来自原生EOG头在额部输入上的估计，不能把89次估计当成89个真实眨眼，更不能当作89次已证实误检。该头的原生类别是BLINK_TASK、水平负／正、垂直负／正；没有私人客观眼位或眨眼标注，故不计算其私人“真实眼动准确率”。

原联合头的开发平均最高分约0.258，故全拒识还有联合分类证据本身不足的原因。修正眼动头不能自动修复联合头的低区分度；动作确认／阈值不参与原始BA计算，不能将低BA归咎于保守动作门槛。

|---|---:|---:|---:|---:|
| REST | 966 | 966 | 0.200000 | 0.200000 |

| 后 | 465 | 20 | 0.008602 | 0.200000 |
| 左 | 360 | 20 | 0.011111 | 0.200000 |
| 右 | 330 | 8 | 0.004848 | 0.200000 |

“权重质量”是每类所有入损失样本权重的总和，不是分类分数。原公式为弱监督掩码乘上1／(5×完整类别更新数)，应改为掩码乘上1／(5×实际弱监督更新数)。0.1的辅助损失系数作用于全部类别，不能消除上述比例失衡。主联合任务和全32路探针的完整监督计权保持原意。

![眼动损失计权对照](眼动损失计权对照.png)

配对验证冻结同一迁移编码器，两条路线从同一私人眼动头初始化，均250次真实优化、相同学习率与数据，唯一干预是上述分母。旧计权的开发眼动预测627／643次偏向REST；修正后为277／643，方向宏召回由约0.22%升至14.63%，但整体BA只19.31%→19.73%，仍接近五分类20%的均衡参照。把修正眼动头以20%融合进原联合输出，开发BA反而低于原模型，保留为负结果。

因此可以确认“损失把方向监督稀释了”，但不能声称计权修正已经提升最终控制效果。仅换线性头和权重仍无法从当前冻结表征提取稳定方向，是继续改进时序表征和补充独立试次的依据。

## 哪些原因有证据，哪些仍是假设

| 问题 | 证据等级 | 本轮解释 |
|---|---|---|
| 眼动弱监督按错误支持计权 | 已确认实现缺陷 | REST占86.21%；已修复、增加回归并做同起点配对优化。不是全部低BA原因。 |
| 原眼动方向头无法触发方向增益 | 已确认当前回放事实 | 最大开发分数约0.386；应先校准私人输入与任务，不能直接给原生EOG分数更大权限。 |
| 当前冻结时序表征欠缺可读方向信息 | 有支持的诊断 | 原眼动／联合潜表示的正则读出开发约20%；显式时间频带特征约33–35%。不等于严格证明表征完全坍塌。 |
| 独立试次少、拟合录制特征 | 已确认样本限制及明显风险 | 每类只有1个完整训练试次；新模型训练100%而开发约35%。相关窗口不能替代独立重复。 |
| REST来源与类别绑定 | 已确认设计混杂 | 训练REST为官方来源，开发为本软件来源；全32路模型开发REST召回9.66%。其具体影响尚未被单独因果隔离。 |
| 额部头皮与公开EOG存在输入域差异 | 已确认合同差异，影响待分解 | 参考、电极、采样率与缩放合同不同；不能通过改通道名消除。 |
| 起始、保持、回中属于不同统计阶段 | 文献及数据支持的研究方向 | 原方向弱监督仅前2秒；右类实际只有8次训练弱监督更新，开发左类起始合格支持只有1次。按钮不是扫视真起点，阶段效果无法可靠估计。 |
| 窗口偏短是唯一原因 | 不支持 | 上轮同权重1.5–8秒延长无明显收益；本轮显式多时标有改善，但与特征、频带和正则读出同时变化，未单独隔离时间长度贡献。 |

## 论文如何约束本次优化

核心期刊Nature Communications官方2025 JIF为18.1，满足先前IF>8要求；IF不作为单篇方法适用本人的保证。[期刊指标](https://www.nature.com/ncomms/)

- **EEG-based brain-computer interface enables real-time robotic hand control at individual finger level，2025**：全头皮与局部输入的消融支持分布式信号整合；在线平滑主要减少标签跳变，没有显著提高分类准确率。这里保留全部32路，并把时空特征与额部辅助共同评估；不期待平滑修复不可分的表征。其手指任务、受试者及监督量与本导航任务不同。[原文](https://www.nature.com/articles/s41467-025-61064-x)
- **Sensory-guided human-machine joint learning accelerates the acquisition of motor imagery brain computer interface control，2026**：强调数据可分性与人机适配，按run更新解码器；这支持检查具体样本与权重。不能把它的训练规模、触觉反馈或任务成绩直接搬到5个训练试次上，也未在本轮部署在线自适应。[原文](https://www.nature.com/articles/s41467-026-75435-5)
- **Malta EyeCon官方数据与原始EOG研究**：明确区分向目标、返回和眨眼；2024非静止头位研究还专门处理基线漂移。本轮因此保留额部极性、加入多时标变化特征，并把任务方向与真实眼位分开。该期刊补充不计入IF>8核心证据。[官方数据说明](https://www.um.edu.mt/cbc/ourprojects/eyecon/eogdataset/)、[2024原论文](https://doi.org/10.1016/j.bspc.2023.105868)

采用0.5／1.5／3／6秒摘要、四个频带、0.1或0.2凸融合系数及0.05正则项，均是锁定的小规模工程对照，不是上述论文证明适合本人的参数。当前是固定多时标特征和1秒指数平滑对照，**尚未实现按信号学习的动态窗门控或客观眼位事件检测**。

## 实现、验证及可复现边界

新增可持续接收新样本的因果特征提取：额部低通8Hz路径保留有符号均值、波动和变化；不再额外加高通，但不能恢复采集时已被硬件高通丢掉的内容。全32路使用0.5–4、4–8、8–13、13–30Hz能量及跨通道相关结构，多路共同进入正则读出。新旧方法使用相同电气QC及重置；UNKNOWN输出进入时间证据，指标只遮蔽未知标签，不把它们当REST。

五个正则读出均250次真实优化：额部156维、全32路1008维、迁移额部潜表示32维、迁移联合潜表示32维、组合1228维。保留已训练OpenBMI／EOG迁移编码器作为固定参照，未更新公开权重。追加两条250次眼动头计权对照。训练与推理均在指定A100隔离目录完成，标准化只用训练角色；两条计权对照使用原允许的连续训练支持。

模型库仍为127个公开模型＋上轮1个研究候选，没有替换当前所选模型。141份来源文件和256个冻结模型权重／manifest绑定均核对不变；测试EEG未打开。新增安全NPZ、锁定协议、原始及更正分母的报告、全部22种开发配置和逐帧预测随证据包保留。多候选及已反复查看开发集带来选优偏差，未提供伪造的独立置信区间。

原始对照报告的动作覆盖最初只按合格帧计分；已按相同源样本索引核对完整回放，将709次开发标签中的预热／坏质量拒绝纳入正式分母，保留原报告而不覆盖。追加配对实验在最后JSON汇总时遇到NumPy整数序列化错误，两个头、梯度历史和预测数组已经提交；最终报告由这些已保存预测在A100恢复，恢复过程零优化更新，未重训补造结果。未来评估入口已修正整数序列化。

完整软件回归510项及42个子测试通过；最后计权／外部实验预算修复后，本地聚焦34项、A100通用36项及最新专门10项通过。代码测试与模型效果分别报告。支持实验、重复或负结果的耗时均纳入总训练预算；计权实验未完整保存精确时长，保守记其锁定600秒上界。

修正已部署到指定A100的版本化训练服务，后续创建的新任务会使用实际弱监督支持作类别计权，并核对外部诊断实验预算。当前所选模型及权重没有因此改变；旧实验仍绑定原始代码，未把旧分数改写成修正后的结果。部署、服务重新连通、模型库128项及推理／动作关闭状态均另存最终回执。

## 下一步保留什么

1. **保留修正后的弱监督计权**，它是训练正确性修复；下一轮整体训练应比较修正前后，不把当前冻结头的小幅BA变化夸大为最终收益。
2. **优先保留全32路显式多时标与有限额部辅助的对照**。10%辅助本轮较稳妥，但差异很小，不能认定为最优系数；暂不接管动作。
3. **保留无眼动辅助、迁移潜表示读出和无JEPA对照**，分离新特征、公开迁移、JEPA和额部信息各自贡献；仅增加维度或拼接全部特征并未带来最好结果。
4. 后续数据继续采“方向眼动＋对应导航想象”，补每个方向多个完整独立重复及同软件合同REST，保留头尾、准备、回中和结束。真实摘戴单独记录，未知阶段不补标签，不要求拆开两种行为。
5. 新采集在使用前分配角色；保留旧测试，不用已反复查看开发结果确认泛化。开始、保持、回中、切换、停止分别看召回、拒识覆盖和延迟；实际EEG→A100→Quest仍按此前约定另行验收。

仍待回答的是：新独立重复能否保留本轮改善，REST来源混杂占多少，真实回中与眨眼会怎样影响停止，以及多时标特征能否融入保持公开能力的紧凑流式JEPA。当前结果支持继续这些对照，不支持把新分类器称为可靠导航意图解码器。
