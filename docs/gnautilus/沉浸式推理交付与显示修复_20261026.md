# 沉浸式推理页面与显示修复

入口：本机中枢 `/lab` →「进入沉浸式推理」。正式进入仍要求四端及模型输入匹配；独立开发回放标识不代表真实设备已连接。

## 页面功能

默认四分格，分别为连接与控制、32通道软件质量及波形、目标VR画面与执行遥测、导航与眼动状态。点击板块标题或空白处放大，其他板块在一侧排列；支持交换主板块和恢复四分格。进入请求全屏，拒绝时铺满窗口。推理和动作分别手动开启；退出及Esc请求停止。

v3 的实验性部署副本为 `aa7926ea82a2aea00d1d1183fa34706a1260eb20d34a1ca7a562f2ef4717f5f3`，来源为 `d5fcad0824c32086f544e9be13612cfbf4d63d2825021ea635d779247df5eecd`。只改变指定模型的实验部署元数据，原权重、策略和历史记录保留。允许实验性LIVE不等于稳定性或独立效果验收。

## 本轮显示修复

- 原过期检查每100ms清空分数、通道及波形，与200ms刷新交替，造成闪烁。现在保留同一来源的上次结果，立即显示过期提示，不把历史结果用于动作。明确停止、换模型和流代次改变后不沿用旧判断。
- 波形请求短暂失败不再清空缓存；显示「上次波形，等待新数据」，时间轴端点为「上次样本」。波形有独立回执时效与流代次检查，不能借状态接口在线把旧波形标成当前。恢复时按原样本游标续接；断流后仍检查流身份。画布尺寸仅在实际尺寸变化时重设，增量滚动只用于呈现。
- 接收器遥测短暂过期保留上次速度、位置及场景，并明确当前状态未知；画面与执行遥测分别计时。旧设备尚未完成的图像回调在切换目标后失效，不能显示为新设备画面。
- 主判断变化时，旧文字向上淡出，新文字向上滑入；相同判断的刷新不重新播放。分数、质量块和眼动事件不再周期性清空后重建。
- 主要标题、传输方式、接纳/拒识状态和执行原因改为中文；保留EEG、VR、A100、RMS等专名、单位和模型身份。
- 右上角「亮色／暗色」切换，浏览器记住选择；卡片、图表、波形、场景和控件一起换色，不发送控制请求或重建会话。
- 放大、交换、恢复四分格采用460ms位置与尺寸过渡。快速切换会取消旧动画，从当前可见位置过渡。遵守系统减少动态效果设置；窄屏使用单列，避免隐式增加第二列。
- 浏览器复核时修复了主判断的嵌套文字被通用样式覆盖的问题，字号和颜色继承主判断；进入沉浸模式后移除普通页面的布局占位，退出时恢复，避免窗口模式出现多余背景滚动。八路波形最小高度为147px，防止720p下通道名称挤叠。
- 常见断网、服务不可达及请求超时提示改为中文，保留服务端提供的具体错误；停止按钮在连接失败后仍可操作。

显示缓存与有效性检查分离。原来的250ms输入/结果时效、300ms接收器时效、质量门、真实输入校验及停止逻辑没有因防闪烁而放宽。上次质量数字的含义是历史评估，接触阻抗仍是未知。

## 验证与边界

- 本轮实际DOM/状态测试覆盖短暂过期、不重复判断动画、切换主题无控制请求、换源清除旧结果、停止可用、迟到画面失效、窄屏布局、减少动态效果及中文网络错误；全部16项通过。后端专项21项通过。
- 全部14个现有JavaScript测试文件通过，结果保存在 `outputs/immersive-20261026/display-web-tests.json`。实际HTTP资源内容与本地源文件哈希一致，见 `display-delivery.json`。
- 在本次显示修复之前，完整隔离回放已运行660.58秒、6067次模型更新，缺包、慢返回和SSH断连注入均有记录，无意外错误。真实A100模型等价性验证覆盖5段、1030次判断，分数差为0，决策无差异。该结果证明当时的软件链路，不是本轮新主题或动画的视觉验收。
- 用户重启后浏览器工具恢复，已实际操作1920×1080及1280×720页面：亮暗主题、四块分别放大、主视图交换、恢复四分格、键盘Enter、32路展开、VR画面/遥测切换、Esc停止与退出。720p实测页面高度720px、波形高度147px，四块无横向溢出，停止按钮在视窗内。退出后普通导航恢复；再次进入不自动开始推理，停止期间仍有质量评估。
- 内嵌浏览器未进入原生全屏；铺满窗口的实际布局已检查，全屏拒绝分支另由DOM回归覆盖。判断进出场与460ms布局动画有专项回归；静态截图不作为动画录像。两个受测页面的浏览器错误/警告日志为空。
- 实际截图：`outputs/immersive-20261026/light-1920x1080.png`、`dark-1920x1080.png`、`light-1280x720.png`、`dark-1280x720.png`；另有放大及32路截图。画面中的VR图样和回执为明确标识的软件夹具，不是真实头显画面。
- 显示修复后的持续回放完成660.12秒、6085次模型更新、3309次聚合状态请求、3299次增量信号请求和3036次图像请求。缺包、600ms慢返回及SSH断连/重连注入后无意外错误，退出码0；本机回放程序峰值RSS约90.6MiB，往返p95为40.35ms、p99为50.20ms。记录在`soak.json`。该内存数值不是浏览器堆或GPU显存。最后的常见网络错误翻译另经第16项DOM测试验证。
- 测试服务按时关闭后另检查了保留历史数据与过期提示；亮色1080p截图记录的是这一断开状态，其余主题截图为运行中状态。测试服务已退出，不保留失效的测试页面。
- 真实采集端、佩戴质量及头显最终验收仍独立进行。本轮没有启动真实采集、推理或动作，没有新增训练或修改门槛。

更新静态资源后，已打开的页面需刷新才能装载新脚本；若当前在推理，应先手动停止后刷新。
