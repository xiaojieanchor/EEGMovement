# 运动想象主线与眼动辅助：目标修正

2026-10-24。依据用户本轮明确回答：**直接想象行走与转向；运动想象是训练主线，眼动只作辅助。** 本说明取代上一份“眼动方向优先”报告中的后续任务优先级和布局建议；已有公开数据结果、模型与验收边界保留，不改写历史。

## 1. 实际任务与标签

采用第一人称运动感觉想象，体会自己行走、转向的感觉；不只是观看自己或场景移动，不要求真实迈步或转身，不指定某只手或腿代表某个方向。允许正常操作手柄，单独记录并控制手柄、头动与提示混杂。

| 导航标签 | 主要运动想象 | 辅助眼动 |
|---|---|---|
| FORWARD | 想象自己向前行走 | 向上看 |
| BACKWARD | 想象自己向后行走 | 向下看 |
| LEFT | 想象自己向左转向 | 向左看 |
| RIGHT | 想象自己向右转向 | 向右看 |
| REST | 明确停止导航想象，无导航意图 | 自然中央注视 |

新模式 `navigation_mi_gaze` 为默认；`navigation_mi_only` 是相同导航运动想象、中央注视的对照。原有 `gaze_only` 仅作辅助分支对照；`paired`、`motor_only` 保留原四肢映射历史语义，不能悄悄更名。

任务绑定 `navigation_mi_gaze_v3` 记录 motor_instruction、gaze_instruction、limb_instruction=NOT_PRESCRIBED、primary_source=motor_imagery 和 auxiliary_source；导航指令与实验模式分别保存。松开、未标注、准备、暂停与断流不补成 REST；提示任务标签仍不是客观测得的意图或眼位。

## 2. 训练主次如何验证

先用运动想象单独条件检查可解码性，再比较同任务的运动想象＋眼动条件；公开 EOG 模型只支撑辅助分支，不用它的准确率替代运动想象成绩。公开肢体想象仍按原生手／脚标签进行方法验证，不能直接改为本人的想象行走／转向监督。

至少保留四种条件，并按完整会话、日期、佩戴分组：

1. 相同四方向导航运动想象＋中央注视。
2. 不进行导航想象、只做四方向眼动。
3. 导航运动想象＋约定眼动辅助。
4. 无导航意图时看周围、眨眼、操作手柄、自然头动，含长时间空闲与主动停止。

额外安排改变眼动与想象配对、相同眼动对应不同想象的受控对照，才能区分来源。运动相关通道与前额辅助通道分别分析；空间位置和频带分支不能自行证明信号一定来自运动想象。现有 CSP／Bandpower 实现排除已定义的前额集合，仍需控制眼动扩散及肌电。深度模型和融合器也必须接受分支消融和来源混杂审查。

融合参数只能在训练内分组预测上选择。不能人为规定“运动想象权重大于一半”就宣称主线已成立；若实际最优只靠眼动，应如实标为辅助分支效果，继续改进运动想象。当前融合器可选到零运动分支权重，此类产物不能称为已经验证的运动想象主导模型。本轮不改权重或阈值抬分，不自动恢复此前取消的四肢训练队列。

报告原始分类、运动想象单独成绩、融合增益、各方向召回、接纳覆盖、无控制误启动率、持续保持、首次响应、切换与停止延迟。个人导航想象的效果仍需对应个人数据，现有公开结果没有证明这四种自然导航想象已经可稳定区分。
