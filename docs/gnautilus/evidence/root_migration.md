## 6. 将厂商的可解释模块转成新的项目基线

### 6.1 推荐分工：算法输出与动作决策分开

![建议的新设备实时数据流](evidence/figures/proposed_pipeline.png)

建议的新链路先将原始输入、特征与动作输出分离。采集层负责字节与时间身份，模型层输出有明确语义的分数和拒识，决策层负责连续意图与动作状态，中枢保留协议、停止和执行回执。这能借鉴厂商的模块化方法，同时保留已有VR工作量；图示为建议架构，未在本轮实现。

| 层级 | 优先借鉴的逻辑 | 需要重新建立的内容 |
|---|---|---|
| 设备与原始记录 | 厂商采样计数、验证位、无线状态、事件及缩放信息 | 独立g.Nautilus设备配置与API绑定，32路名称／端口／单位映射 |
| 因果信号处理 | 保持状态的频带滤波、功率与空间滤波 | SMR、低频MRCP、眼动分别定义处理流；跨包一致，缺口重置 |
| 特征与分类 | 简洁Bandpower、CSP＋分类器 | 训练折内拟合、正则化、小样本验证、无控制建模与校准 |
| 决策 | 零类拒识、证据累计、模式切换的设计思想 | REST与拒识分开；只有新样本证据推进确认；平滑只归一个层级 |
| 反馈 | 训练／反馈分离、事件记录、分类轨迹显示 | 以实际执行回执表示VR动作；记录用户任务、视觉刺激与反馈来源 |

### 6.2 三条处理分支解决不同问题

**感觉运动节律分支**用于持续运动想象与运动状态。以CSP＋收缩LDA为首个可解释基线。比较一个预定SMR频带与受控FBCSP，不在留出集上反复挑频带。FBCSP原始研究给出训练数据学习滤波空间、特征筛选和分类器的流水线；其多频带思路值得采用，原文分类器并非本文建议的收缩LDA，二者不能混称复现。[Ang等，2012](https://www.frontiersin.org/journals/neuroscience/articles/10.3389/fnins.2012.00039/full)

**低频运动准备分支**用于探索自然意图启动。它与SMR分支承担不同任务，不能用8–30 Hz输入声称已经研究了低频MRCP。先建立单向因果滤波与历史缓冲，再检验动作前／动作后证据和误触发。自然方向类别从任务定义和新数据建立，不把公开左手标签直接改写成“左转”。

**眼动辅助分支**用于用户允许的方向信息。保留符号与低频眼位变化；独立记录有意控制和自然眨眼。明确眼动方向、扫视起点、保持与回中各自的表现。它可以帮助早期控制，也可以做信号来源对照；不是先全量去眼动再期望该分支恢复方向。

三条分支不要求一开始全部启用。先固定设备和基线，逐一增加，比较增量收益。动作执行层可以用无控制门抑制输出；若后续采用联合可训练网络，训练时不得用预测硬门控把方向损失截断。可以使用并行损失、联合标签或有明确监督条件的掩码，均需以梯度与数据支持验证，而不是把执行门控搬进反向传播。

### 6.3 基线与研究候选的采用顺序

| 路线 | 推荐用途与依据 | 代价、限制及替代办法 |
|---|---|---|
| Bandpower＋线性分类 | 最先验证信号、时间身份和用户训练；能解释各频带贡献 | 少数通道／特征可能无法区分多方向；失败先检查信号和任务支持，不只扩网络 |
| 正则化CSP＋收缩LDA | 第一主基线；适合感觉运动区覆盖下的小规模个体数据 | 对协方差、参考、坏通道和会话漂移敏感；固定通道子集或预先训练若干模式，不临时删CSP输入 |
| 受控FBCSP | 对个体频带差异做有限比较 | 参数和选择层增加；所有频带选择在内层训练验证，保留单带对照 |
| 正则化协方差＋Riemann MDM／切空间线性模型 | 与CSP作不同归纳偏置的基线 | 通道／参考变化仍敏感；低秩和协方差估计必须处理，跨域对齐仅训练／开发拟合 |
| EEGNet类小模型 | 数据充分后比较可学习的时空特征 | 原研究包含跨范式实验，但不保证本设备或自然方向；部署时核查卷积／填充与窗口因果性 |
| MRCP检测＋持续SMR解码 | 分开探索自然启动和持续意图 | 启动可检出不代表方向／速度可解码；无法稳定提前时报告实际检测延迟并保留SMR辅助 |
| JEPA类预训练 | 只有在新数据与基线明确后作为候选 | 需要验证空间输入适配、预训练暴露、目标时间边界和实际跨会话增益；失败回到简洁基线，不恢复旧权重 |

Riemann路线来自对EEG协方差的几何分类方法，本文不引用其历史准确率作为新设备预期。[Barachant等，2012](https://pubmed.ncbi.nlm.nih.gov/22010143/) EEGNet以深度可分离卷积学习时空结构，适合作小模型对照，而不是“更大必然更好”的理由。[Lawhern等，2018](https://arxiv.org/abs/1611.08024)

JEPA不必继续绑定旧实现。S-JEPA提供EEG空间掩码与跨范式下游研究的依据，但只支持候选路线的合理性。[Guetschel等，2024](https://arxiv.org/abs/2403.11772) 截至本次检索，Laya预印本进一步研究潜空间预测；其摘要着重临床任务和冻结线性探针，不构成本项目自然意图或低延迟控制证据。[Panchavati等，2026预印本](https://arxiv.org/abs/2603.16281) 第一轮不安排大规模预训练；先用同一组独立会话比较基础方法。

### 6.4 真实静息、拒识和故障必须保留不同身份

| 状态 | 定义 | 动作与记录规则 |
|---|---|---|
| REST／NC | 有有效监督依据的无控制意图 | 可以用于无控制分类；保留环境、眼动与头动条件 |
| UNKNOWN | 未标注、任务准备或意图时点无法确认 | 不补成REST；可记录和分析，不进入伪造的静息监督 |
| REJECT | 有效输入但模型证据不足或类别之外 | 输出拒识原因、分数与覆盖；执行零动作，不改写原任务标签 |
| INVALID | 断流、包无效、参考或接触质量不可用等 | 重置受影响状态并停止；不作为模型“准确预测静息” |
| WARMUP | 缓存或因果状态支持不足 | 保存预热时间与样本支持，计入覆盖率总时间／事件分母，单列不可用时间，不计为有效输出 |

初期不必一次训练四个自然方向。可先做REST＋左右手MI两类意图的受控比较，或把脚MI映射为前进。映射表保存在独立任务配置中，原始标签仍写RIGHT_HAND_MI／LEFT_HAND_MI／FOOT_MI。用户真实做动作、仅想象动作、仅眼动也分别编码，不能混成同一神经标签。之后才加入自然前进／左转／右转任务；后退与组合动作是否可分由新数据决定。

## 7. 输入、模型与现有中枢的接口边界

### 7.1 Python API提供后需要确认的最小数据契约

下表是建议接口内容，不是厂商API的真实函数或返回字段。先读取实际API、示例和服务版本，再编写字段映射。采样率、单位、传输步长与32路的排列均从实际配置读取和实测确认。

| 数据层 | 最少保存的身份 | 作用与失败处理 |
|---|---|---|
| 设备配置 | 型号／序列号、固件／服务／API版本、32路端口及头皮名、REF／GND、滤波／CAR／DRL、缩放 | 配置变更建立新段，不能沿用旧空间模型身份 |
| 原始批次 | 录制与source epoch、首样本号、样本数、计数器、主机接收单调时间、设备时间可用性 | 检测重包、倒序、间断；不使用主机到达时刻伪造真实采样时刻 |
| 信号与辅助量 | EEG数值及原生单位、增益／偏移、验证位、链路质量、电池、加速度、数字输入 | 辅助通道分离，不塞入32路EEG；测试信号与真实电极源明确标记 |
| 质量判断 | 支持样本区间、判断可用时刻、有效通道及理由、参考／饱和／接触／数据有效性状态 | 在线不回填未来判断；仅改变单通道状态不足以保证固定CSP仍有效 |
| 模型输出 | 模型与预处理哈希、原始标签／映射版本、样本支持、分数语义、拒识／预热原因、完成时间 | 无效分数和过期结果直接拒绝，不能把距离包装为归一化概率 |
| 动作输出 | 唯一决策ID、源epoch、设备／模型身份、目标轴、停止原因、命令时效 | 一次推理被心跳重发仍是一次证据；接收端执行后返回回执 |

记录原生值和版本化派生值，缩放只做一次。单位未知时保持未知并阻止模型输入；不能凭波形看起来像脑电猜成微伏。配置和数据清单的哈希与可重建记录一起进入新阶段治理入口，不调用已归档的旧训练检查器来冒充新能力。

### 7.2 现有代码哪些可保留、哪些应有边界地替换

当前`configs/device_transition.json`明确新设备未接入、新模型未选定，旧设备与旧模型入口关闭。`training/action_schema.py`保留五类与九类动作及边缘化处理；`hub/intent_control.py`仍只接受长度5或9的规范化分布，并包含旧通道默认值。`hub/intent.py`的`effective_mask`直接要求七槽。因此保留控制框架并不表示其输入外壳已经兼容32路。

后续优先替换采集适配、质量语义、特征模型和输出映射；在设备中立的边界输出新模型结果。二分类LDA只有两个分数时，不能凑成五类／九类概率再满足旧接口；应增加显式的新输出适配层或版本化决策接口，标明尚未支持的动作。校准后的概率与未校准的margin分开处理，映射不制造原模型没有的类别证据。

现有控制的有价值部分包括：新样本确认、源／模型切换重置、时效检查、紧急制动、独立动作使能及真实执行回执。`protocols/execution-v1.md`还保存HMAC签名、接收端ticket时钟、序号和租约的设计。其数值阈值与部分“需校准”文字属于旧阶段记录，不能作为本次更改依据。当前用户规则优先：推理与动作独立手动启动，可选模型校验不授予启动资格；新设备仍需真实输入、质量、新鲜度与停止边界。

本轮不修改这些接口或阈值。为下次实施提供的具体顺序是：新设备输入契约→设备中立质量事件→原始记录／重放→固定特征基线→模型结果适配→仅监测→用户手动启用动作→真实VR验收。旧通道数、损坏规则、设备QC数值和概率阈值均不直接复制。

## 8. 连续控制、延迟与速度：需要分别验收

### 8.1 五种时间量不能互相代替

| 时间量 | 测量起止 | 报告方式 |
|---|---|---|
| 输出更新间隔 | 相邻独立样本支持的决策输出 | 实际P50／P95／最大值；重复发送不计新更新 |
| 历史窗口／预热 | 首次可用真实样本至特征充分 | 按各分支分别列出；长窗口不等于每次必须等待同样时长 |
| 计算与传输 | 批次收齐→处理→推理→命令→回执 | 本机单调时钟与接收端时钟分别记录，跨机不直接相减 |
| 首次检测响应 | 预注册事件锚点至首次正确稳定输出 | cue锚点、动作实测锚点和主观意图锚点分别标明 |
| 停止／切换响应 | 独立释放／故障锚点至实际执行回执 | 正常停止与断流／急停分开；停止优先于平滑 |

建议部署目标为独立决策每100ms更新一次，验收P95小于500ms的操作间隔。100ms是新方案建议，不是厂商API的保证。首次自然意图检测能否小于500ms单列结果，不用更新快来代替。1.5秒滑窗可以每100ms出一次分数，但窗口尾部之前的旧状态会影响切换和停下；需要测量响应曲线与误启动，不能将窗长简单加到每帧延迟，也不能完全忽略。

总延迟中，设备／无线缓存、API交付、因果滤波群延迟、特征积累、模型计算、证据累计、网络与VR显示各占不同部分。SMR功率、低频MRCP和SSVEP不能共用一个“滤波延迟常数”。若没有显示帧或光学测量，回执只表示执行程序已应用动作，不声称用户眼前像素已经刷新。

### 8.2 先做平滑速度控制，再决定是否研究速度解码

初期用固定的安全目标速度和转速，通过连续控制策略平滑改变；意图成立则向目标速度过渡，正常释放减速，无效输入或急停立即制动。若可调节速度档位，单列为操作策略。这些都不是直接解码了用户主观速度。

分类margin、softmax最大值、票数或显著性p值均不能天然表示意图速度。只有定义了速度任务、可记录的监督目标和跨会话回归指标，才能研究连续速度意图。评价应包含误差、迟滞、速度变化的连续性、停下距离和高低速混淆；不能仅展示平滑曲线。自然速度难以稳定辨别时，保留固定速度或显式档位，不为完成指标而重新命名置信度。

## 9. 新设备验证方案：先辨信号来源，再评估闭环收益

### 9.1 先固定标签和来源对照

| 任务组 | 要分清的问题 | 必须保存的条件 |
|---|---|---|
| 眼睛居中、左右手／脚运动想象 | SMR是否有可迁移的分类支持 | 不做实际动作、任务与提示事件、持续区间 |
| 仅有意眼动，不做MI | 辅助方向信号能否独立解码 | 扫视起始、持续眼位、回中、中途启动 |
| MI＋眼动一致／不一致 | 混合收益与信号主导来源 | 同向、相反、缺失一模态分别统计 |
| 实际动作与仅想象 | 解码是否依赖动作／肌肉／帽体移动 | 动作真值或人工观察依据，EMG可用性明确 |
| 被动看提示／被动看VR反馈 | 是否识别了视觉提示或反馈而非意图 | 刺激编码、画面条件、输入装置事件 |
| 静息、自然眨眼、头动与重新佩戴 | 无控制误触发、接触变化与漂移 | 对照任务原标签，不一律改成REST或全部剔除 |

头动对照可以同时暴露真实的质量问题与算法误判。报告中分开“因质量拒绝的时间”和“质量合格但错误触发的时间”。不能通过只保留安静好信号来隐去实际使用覆盖率。若没有客观眼位／肌电传感器，标签写明按指令执行或观察，不能事后补成测量真值。

### 9.2 建议的首轮个体实验预算

先锁定训练会话和开发会话，跨至少两个日期；最后单独安排一个新日期、重新佩戴的留出验收。具体预约可变化，分组边界不变化。每次重新佩戴产生新的wearing_id；同一连续录制切出的相邻窗口不能分别进入训练和测试。

建议前期每个任务类先收集20个5秒有效尝试，配2秒准备与3–5秒随机间隔，分成短block；持续保持另收3／5／8／12秒区间。这里的20次是预算起点，不是保证够训练的样本量。每个阶段记录取消与失败，不自动排除。按真实支持决定能训练几类，若关键类缺样本先补采，不用类权重掩盖缺口。

开发阶段分别包含至少10分钟可用无控制时间，和眨眼、头动、提示观察等负对照。最终连续验收目标包含至少30分钟可用无控制暴露与各类至少20次尝试，可分休息段完成。若无控制30分钟内零误启动，在独立泊松事件近似下，95%单侧上界仍约为3／30=0.10次／分钟；这是统计边界，不等于证明绝不会误动。事件有聚集时还需按会话报告区间。

初期MI映射闭环通过后，按相同分组建立自然前进／转向任务。自然意图开始时点不能精确观测时，使用预注册提示或动作锚点并承认其代理属性。不能把按钮按下或动作发生时刻直接写成脑内意图的真实开始。

### 9.3 训练和选择必须在分组边界内

![训练、选择与验收的数据边界](evidence/figures/validation_split.png)

第一轮固定Bandpower、CSP＋收缩LDA两个核心基线，再加入一个Riemann基线；EEGNet与预训练模型只有在前述证据明确后扩展。模型选择按开发集的识别、覆盖、误启动和延迟联合评估，不以训练分数排序。不得把最后留出集当额外开发集反复换阈值。

建议比较0.5／1.0／1.5秒因果SMR窗，100ms更新；这是待实验参数网格。低频MRCP单列候选历史长，不套该网格。滤波参数、参考、空间投影、标准化、特征选择和概率校准只从训练／内层开发拟合。滤波跨完整录制连续处理；断包、无效样本或跨录制重置，避免反射填充或零相位滤波借用未来。任何监督滑窗均按原始来源分组，滤波影响范围也记录在边界审计中。

公共资源只作为方法／迁移对照，不直接提供私人导航标签。BCI Competition IV Dataset 1的持续输入和无控制段，比只给固定试次的资料更接近连续识别问题；但它仍有实验提示，并含人工生成资料，需区分真实来源。[官方说明](https://www.bbci.de/competition/iv/desc_1.html) 其原始研究明确把无控制纳入建模，是设计异步基线的参考。[Zhang等，2012](https://www.frontiersin.org/journals/neuroscience/articles/10.3389/fnins.2012.00007/full)

PhysioNet EEG Motor Movement／Imagery提供实际与想象动作资料，可用于比较两者；标签T1／T2的含义随run变化，必须读取run协议，不能一律映射同一方向。[官方数据页](https://physionet.org/content/eegmmidb/1.0.0/) 本轮不下载大库，不扫描或重启旧公共预训练队列。

### 9.4 报告指标和建议进入条件

| 指标 | 分母与定义 | 首轮建议采用方式 |
|---|---|---|
| 平衡准确率／混淆矩阵 | 对预注册有标签、真实任务逐类统计 | 训练、开发、独立留出并列，列出各类事件和样本量 |
| 覆盖率与含拒识成功率 | 全部预注册任务时间／事件，含拒识与预热 | 拒识不从总分母消失；质量失败同时单列 |
| 无控制误启动 | 符合预定义进入条件的错误动作事件／可用无控制分钟 | 连续错误运动计一个事件并附持续时间，不能按网络包计数 |
| 漏检与切换 | 意图尝试数、保持成功时间、正确方向切换次数 | 开始、保持、中途启动、回中分开 |
| 时延 | 输出间隔、锚点检测、命令回执与停止 | P50／P95／最大及超时比例，按源时钟说明测量边界 |
| 故障恢复 | 注入故障数、停止与状态重建结果 | 断点后清空滤波、方差、递归与后处理历史并预热；通道／参考／模型身份相同可保留冻结CSP矩阵，配置改变须切换匹配模型或拒识 |

用于早期探索的建议门槛是：开发集任务事件成功率至少70%、覆盖至少80%、无控制误启动不高于0.1次／分钟，并满足输出更新P95<500ms；这是作者提出的候选进入条件，不是用户既定要求或已达成绩。独立留出按同口径完整呈现置信区间；是否进入自然意图阶段还需类别支持、误动持续时长和用户体验共同判断。不能为了达到这些数值放宽质量、删拒识或重标静息。

### 9.5 需要覆盖的故障与兼容场景

实际API到手后，先用厂商内部测试信号做采样／缩放与时间身份检查，标记TEST_SIGNAL，不称EEG验收。随后测试断开／重连、计数器回绕与重置、丢包、重复批、倒序、无效验证位、低电量／无线变差、通道或参考失效，以及配置改变。重连新建source epoch，待真实缓存恢复后重新输出，不拼接断点。

模型切换和设备配置改变要清空后处理历史；停止、急停和采集中暂停执行不依赖模型判断。检查独立手动启动、可选校验失败不锁启动、无回执显示状态未知、陈旧结果不得继续驱动。合成故障测试能验证软件规则，但最终仍需新设备真实录制和VR显示验收。

## 10. 采用清单与下一步实施顺序

| 分级 | 采用项目 | 下一步实际动作 |
|---|---|---|
| 优先借鉴 | Bandpower、CSP＋简洁分类、训练／反馈分离、原始事件和质量身份 | 获得Python API后先做输入映射、记录与固定基线；以新配置和治理入口运行 |
| 优先借鉴 | 中枢统一决策、新样本确认、执行回执与停止 | 保留原接收协议，增加明确分数语义的设备中立模型接口 |
| 需要改造 | CSP试次裁剪、特征窗、导出参数和CV | 以32路EEG契约重写；训练折内重拟合；修正示例条件分支和导出歧义 |
| 需要改造 | Add zero class、投票、EOG方向 | 拒识与REST分离；预注册时间累计与停止；保留眼动极性并验证保持段 |
| 保留研究 | MRCP自然启动、Riemann／EEGNet／JEPA、自然方向与速度 | 同一新会话协议下逐项比较，不由模型规模决定采纳 |
| 当前不采用 | 将原SSVEP／P300默认配置当自然意图低延迟方案 | 若需要菜单辅助再单列刺激范式和体验验证 |
| 当前不采用 | FES／TMS、fNIRS、眼动仪及旧Oculus运行链的整套迁移 | 只借鉴相应算法或接口思想，未提供额外硬件与兼容证据前不引入运行链 |

实施分为四个独立验收点：①实际API与32路真实输入、原始记录和质量；②固定特征与独立会话识别；③含长静息的连续拒识、保持与停止；④用户手动启用后的真实VR闭环。每点保存可复核输入、配置、代码和结果哈希。失败发生在哪一层就先修该层，不以换大模型替代设备或标签问题。

仍需核实的具体事项为：湿电极型号与附件、端口到头皮位置、REF／GND与Z-channel、实际采样率与API缩放、设备／主机时间关系、许可证和MATLAB兼容环境、Python API版本与示例。它们已形成明确核查任务，不妨碍完成本轮材料分析；未核实前不生成可运行的设备配置或性能承诺。
