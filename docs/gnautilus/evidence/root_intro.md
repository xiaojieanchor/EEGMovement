# g.Nautilus 32通道与Simulink迁移分析

2026年10月22日｜EEGMovement｜32通道湿电极｜源码、模型结构与原始资料核查

## 1. 技术结论：先迁移可解释闭环，再验证自然运动意图

g.Nautilus为这个项目带来的主要机会，是能够围绕感觉运动区重新配置空间覆盖，并使用具有明确采集、训练、分类和反馈分工的工具链。换设备本身不会保证识别准确率提高。需要重新建立电极映射、输入缩放、因果处理、会话独立验证及连续无控制状态，才能判断新增信号是否有效。

最值得优先吸收的是**频带功率／CSP空间滤波、简洁分类器、训练与反馈分离、信号质量与事件身份、可审计的连续决策**。建议保留现有VR和控制接收链，在独立的新设备配置下重建这些环节。现阶段不宜直接把厂商演示中的分类结果接成VR动作，也不宜预先认定应继续使用旧JEPA网络。

报告依据用户已确认的32路湿电极、可调整布局展开。长期目标是自然的移动意图；左／右手或脚的运动想象、眼动方向可作为前期辅助。识别“右手想象”后映射“右转”，在产品上可以有用，但它与直接识别自然右转意图属于不同任务，应保留不同标签、指标和能力声明。

### 1.1 最影响实施的核查结果

| 核查结果 | 具体含义 | 对本项目的决策 |
|---|---|---|
| 两个软件目录中共有84个模型／模板载体 | 56个SLTX、27个SLX和1个MDL；83个压缩模型静态读取成功 | 已建立逐文件清单、结构与依赖证据；仍需合法MATLAB环境做运行验证 |
| 所给g.HIsys与g.BSanalyze手册均为1.22.01／2022 | 当前官网描述可能包含更新功能 | 以本地版本的实际文件为准，官网只补充能力和版本差异 |
| CSP批处理把时间、触发当作数据矩阵首尾列 | 某“32列”分支实际上加载30 EEG通道布局 | 新设备32 EEG通道不得按示例原样裁剪或编号 |
| 三分类示例是RIGHT／LEFT／FOOT | 第三类不是静息 | 必须另行设计无控制样本与拒识，不能把FOOT重命名REST |
| Add zero class属于拒识机制 | 分数不足时输出0，不等于学会自然静息 | 以不同状态保存REST、UNKNOWN、REJECT和质量失败 |
| 示例的100:100评分与挑时点用于拟合／选择 | 不是新佩戴独立准确率 | 所有空间滤波、特征选择和阈值须在分组验证内重建 |
| 多数投票库的保存默认开关未启用 | 有投票模块不等于演示已默认稳定化 | 决策层由中枢统一拥有，逐项测量平滑带来的延迟 |
| 某些模板中的输出是判别距离 | Bandpower FES中为WV线性判别后乘0.2 | 不可作为概率、意图速度或与旧概率阈值直接比较 |
| EOG演示主要做峰检测／行列扫描 | 不能直接完成持续左右眼位与方向控制 | 有意眼动保留极性，另做扫视／保持／回中实验 |
| SSVEP默认示例依赖秒级缓存与滤波 | 手册给约3秒平均响应的解释 | 可作辅助菜单或基线，不作为500ms自然意图的现成答案 |

上述算法细节在后文对应章节给出源码行、模型内部块或手册页码。它们描述所提供资料的可见实现与边界，不代表其他版本必然具有相同问题。

## 2. 资料构成、版本与静态分析方法

### 2.1 两个目录是互补材料，不能简单互相覆盖

`g-tec/`主要保留用户示例、批处理、范式文件、测试数据与VR相关资料；`programfile_gtec/gtec/`主要包含安装目录结构下的库、受保护实现、帮助文档和硬件配套组件。这是对本次文件分布的归纳，不是对其来源目录的安装授权。

本次对4,188个登记文件重新计算SHA256，与`devices/gnautilus/supplied-materials.json`逐项一致，无新增、缺失或内容变更。两个目录加中文PDF总计约1.294 GB十进制字节规模。发现218组相同内容，涉及267个冗余副本，其中44组跨两个目录。相同文件可以在分析索引中合并引用；来源目录保留原样，不以去重名义删除。

| 材料 | 本次数量或版本 | 应如何使用 |
|---|---|---|
| MATLAB可读脚本M | 241份，包含第三方与接口封装 | 先辨别是真实算法、示例脚本还是注释包装器 |
| P-code | 1,995份 | 可确认文件与依赖身份，不宣称已读到源算法 |
| MEXW64／DLL | 88份／278份 | 核查入口、平台依赖和调用关系，不在本轮执行 |
| SLTX／SLX／MDL | 56／27／1 | 全量静态解析，重点族作语义拆解 |
| MAT | 190份 | 示例参数、范式或示例录制，不自动作为用户新设备训练数据 |
| PDF | 84份，含中文手册 | 其中大量是侵入式电极产品资料，与本项目32路头皮帽无直接关系 |
| g.HIsys手册 | 637页；1.22.01，2022 | 主要算法、设置、范式和VR说明 |
| g.BSanalyze手册 | 499页；1.22.01，2022 | 离线特征、分类与统计语义 |

g.HIsys的`Contents.m`明确标注Version 1.22.01 (R2022 Win64)，与本地手册一致。但`info.xml`的旧字段如`matlabrelease=14`不能单独解释为已验证兼容的MATLAB版本范围。模型自身保存时的Simulink版本也只表示文件元数据，不保证当前环境可以加载全部依赖。当前[g.HIsys官方页面](https://www.gtec.at/product/ghisys-biosignal-acquisition-analysis/)说明的实时分类、闭环及多模态能力，为生态定位提供补充；本机许可是否包含这些组件仍未核实。

### 2.2 模型解析追踪至块与连线

SLTX先读取`fsroot/*.slx`，再解析内部`simulink/blockdiagram.xml`与`simulink/systems/*.xml`。保存源容器SHA、内部SLX SHA、块SID、类型、属性、Mask、连线及分支、库链接、S-Function与回调。MDL按层级对象和文本行号解析，不求值任何表达式。

83个SLX／SLTX共读取2,068个结构块；不把`bddefaults.xml`中的默认块模板重复计入。MDL的文本与层级解析结果另存，不能把包含默认项的`BlockType`文本命中次数当实际运行块数。库中存在某模块与模型真正使用该模块分开记录；仅按同名文件找到的依赖候选，也不当作MATLAB搜索路径已经解析成功。

证据入口为`evidence/model_index.csv`、`model_index.json`、`models/M001…M084/structure.json`及对应XML。所有84项的用途、关联程度、结构状态和采用建议见附录。对重点族继续追踪MATLAB、受保护函数和手册，形成后续章节的分析卡片。这个覆盖范围表示材料审查覆盖，不等于84项运行测试通过。

### 2.3 页码、引用与结果口径

手册同时记录物理PDF页和页面印刷号，例如“PDF292／印刷276”。不同部分存在前置页与编号重启，禁止仅用一个固定偏移换算全书。源码引用按本次原字节文件的行号，模型引用按容器内XML路径＋块SID。网页与研究记录访问日期2026-10-22，引用原始论文和官方文档，不将营销描述视作本设备性能测量。

默认以个人适配为首阶段。跨用户、跨日期、重新佩戴、VR运动干扰是不同难度的验收条件；本文提出的预算和阈值为建议预注册方案，均未执行。旧训练分数不参与新设备方案的成绩比较。
