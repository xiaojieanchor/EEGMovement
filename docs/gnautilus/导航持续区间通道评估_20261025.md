# 导航持续区间通道评估协议

目标：按人工起止眼动界定持续联合任务区间，分析同方向跨试次相似性、异方向差异及通道冗余，提出下一轮导航模型通道候选。当前不能把区间直接等同于纯运动想象。

- 仅train和validation，test不读取；不拟合分类器、不更新JEPA、不调整上线权重。
- 主范围为人工onset结束+1秒至offset开始−1秒；两个方向事件必须都marked。敏感性为两侧各0.5秒。尾部事件不完整但起点已框选，不影响其之前范围的上界。
- BACKWARD训练缺offset，RIGHT验证缺onset；严格主分析剔除这两个试次并列出原因。不能用absent补造眼动边界。
- 原始32列不变：CH16=Cz、CH19=C5。先对32路全量评价；运动候选主要在FC/C/CP/P24路中比较，同时保留额部排名作混杂诊断，不断言额部与行走想象无关。
- 因果8–30Hz四阶Butterworth滤波，从onset结束处重置，不使用任何眼动原始样本支持；主范围留1秒滤波建立时间。另分析0.5–4Hz，仅作低频共同变化指标，不称眼动真值。共同平均参考仅是明确标注的二次敏感性处理，原始单极参考不改写。
- 纳入持续区间中全部非重叠2秒完整窗口；试次贡献等权。不足2秒的末尾残余继续保存在原始完整记录，不补零参与等长频谱比较。保留既定电气质量审计及原始范围，不删原始信号或改标注。
- 每通道两个log功率特征：8–13Hz、13–30Hz。Fisher型分数为三类训练质心之间方差／类内窗口方差，训练均值/尺度仅train拟合。同方向训练仅1试次，类内值只代表同试次稳定性，不是独立同方向重复。
- 用训练平均谱作频率参照，比较允许的验证试次与同方向/异方向训练谱的余弦相似性；只对FORWARD、LEFT有严格跨角色重复。BACKWARD、RIGHT缺少对应支持时不填分数。
- 多通道比较8–30Hz相关矩阵、方向间矩阵差异、与额部的相关程度。高相关反映耦合或共同参考，不自动代表冗余或脑区因果贡献。数据选通道时以训练相关冗余阈值0.95作探索性补充。
- 固定候选：运动区24路、训练分数top4、top8、top12、去高相关top8、解剖中央12路。所有名称/物理索引/排序在验证读取前冻结；验证只复核，不重新挑最高通道。无4方向独立支持，不输出“四方向最优”结论。
- 全部真实信号处理在既定A100隔离代码目录，固定GPU UUID，最多900秒；绑定原始数据、人工修订、源代码、选窗范围、角色和质量回执。0次梯度、无注册表修改。

证据输出：32路差异/相似性表，训练/验证覆盖清单，按方向相关矩阵，训练排名及敏感性，冻结候选与复核；图表和可复核JSON/CSV存本聊天outputs，内部派生放统一数据集.metadata。
