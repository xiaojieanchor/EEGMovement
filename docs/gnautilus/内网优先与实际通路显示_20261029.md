# 内网优先与实际通路显示（2026-10-29）

## 实际通路

中枢总览、连接信息、联调页和沉浸推理页分别显示 EEG 输入与 Unity 执行回执的实际路径，不能因为公网身份在线就认定数据经过公网。

- EEG `lan_ws`：内网直连；`public_relay`：公网中继。
- Unity：根据中枢实际接收端点区分内网直连、内网／本机和公网中继，不接受客户端随意声明通路。
- 旧 TLS 独立入口仍标为 TLS 直连；没有网络范围证据时，不将其猜填为公网或内网。
- 断线后保留最后使用路径及等待状态；上次路径不代表当前已经连接。

## Quest 连接选择

已有自动登记身份的 Quest 启动后，先探测缓存的内网地址与 UDP 局域网发现结果。候选地址只作为提示，必须同时通过设备身份的签名 HTTP 响应，以及带随机挑战的签名 UDP 回包；回包还需匹配本次中枢会话。

探测成功后，状态请求、主动打标、预览和动作接收均走内网；公网连接保留为备用、更新通知和离线事件补交。公网签名响应还可提供当前中枢的私网地址提示，供广播被隔离但单播可达时使用。首次身份登记仍走原有自动流程，无需用户导入配对文件。

内网探测大约每3秒进行一次；连续两次失败才切到公网备用，连续两次成功才从公网返回内网，避免一次探测波动造成反复切换。HTTP 与 UDP 均绕开系统代理，自动探测仅接受私网 IPv4。显式旧式 LAN 登记继续兼容。

网络任务异步运行，不在 Unity 帧循环内扫描地址、等待 HTTP 或等待 UDP。候选数、请求时间和发现时间均有上限，不扫描任意端口。

## 切换与停止

切换时清空待执行包、票据和旧握手，保持人物停止，恢复动作须手动复位；旧公网包不能进入已切换到内网的接收器。切换不会主动调用采集取消，也不改变用户打开的页面。显式急停仍保留原有取消行为。

公网备用连接重连时，中枢和头显先检查是否正在使用健康的内网路径。仅备用公网发生波动，不关闭正常内网路径上的动作授权。EEG 本身中断、动作过期及显式急停仍独立处理。
