# 新设备迭代设计：先取得信号证据，再形成自主控制模型

用户授权依据：2026-10-22明确要求制定迭代计划，并允许在提供Python API之前开始其余分析和构建。按当前AGENTS的自主实施要求执行，不为常规方案选择增加重复审批。设备接入、API调用和实际VR／网络链路留待API提供后实施。

## 已确定的目标与边界

- 主目标：32路湿电极下，自然运动意图的开始、方向、保持和停止；早期允许眼动或手脚运动想象映射。
- 主推荐布局采用上一报告A，B保留为眼动辅助对照条件。编号只是研究编号，REF/GND/Z-channel及实际端口仍未核定。
- 第一模型为因果频带功率／正则化CSP＋收缩LDA参照；连续拒识和状态决策单列。MRCP低频分支与自然方向单列验证。置信度不当作速度。
- 新代码位于独立`gnautilus_lab/`，不导入旧training／hub，不启动端口、设备、服务器或训练；无权恢复旧权重、队列与七槽参数。
- CPU只运行显式合成数值单元测试；本轮不对真实EEG拟合、评分或运行诊断。真实训练／模型／诊断入口需新协议与指定第二A100的实际执行证据，不因离线核心存在而宣称入口已就绪。

## 本轮构建的可检验单元

1. 数据与实验契约：32路身份、明确单位／采样率、会话／日期／佩戴／来源分组、原生任务与角色；未核定字段拒绝进入分析。公开数据默认隔离，不自动成为预训练资料。
2. 因果数值核心：分包一致的有状态滤波、缺口重置与预热、描述性频带功率；电气质量资格依实际设备独立验证，不默认至少4路或旧阈值。
3. 参考模型核心：正则化CSP、对数方差、收缩LDA、原始margin及冻结模型元数据；训练变换只在训练折估计。仅合成测试验证数学与导出一致性。
4. 评估核心：按组验证、训练折内重拟合、事件级指标、拒识／预热覆盖分母、误启动率上界、按会话不确定性和分组置换规则；少量组不得标高置信。
5. 离线决策：接受明确的概率语义与源身份，保留REST／UNKNOWN／REJECT／INVALID／WARMUP；新样本证据推进状态，缺口／源切换停止，禁止输出实际设备命令。
6. 调试与审阅：故障矩阵、真实硬件前置核查、MATLAB可选参照与部署取舍；不编造新版工具箱或下载成功。

## 实施与技术选择

首选Python自主可解释核心。现有MATLAB batch只作算法／参数参照，不封装为默认生产服务：已知输入列约定、CV、坏道与导出问题必须在重实现中消除。MATLAB合法环境可作为对照计算器；Engine、Compiler SDK、Production Server等许可、受保护S-Function支持与版本兼容分别核实。暂不建立服务进程或网络中间层。

所有数值核心都是未验收的研究组件，无真实硬件能力声明；命令行只做契约／协议检查与能力说明。本轮可执行结果是合成回归、准入检查和新文档。实际信号是否包含目标信息，必须按跨日新佩戴及来源对照取得证据，工具本身不能替代这些数据。

## 验收

新增测试先失败后实现；覆盖分包／缺口、未来样本影响、训练折隔离、同源重贴／日期佩戴泄漏、未知元数据、类别语义、CSP固定维度、CAR秩、margin不是概率、重复decision不计新证据、误启动和覆盖统计。官方资料与小数据只下载不执行，逐项保存SHA与许可／状态，未知准入拒绝。最后重核保留系统和原材料哈希。
