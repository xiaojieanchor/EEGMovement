# 总览指标与逐通道电气检查（2026-10-29）

## 页面与统计

移除总览顶部过时的设备切换提示，保留原有导航及四张指标卡。补齐以下测量，配置采样率、接收实测率、软件电气检查和原厂接触阻抗分别表述。

1. **接收实测率**：在中枢接纳实时块时，按实际样本数量和中枢单调时钟记录，使用约2–8秒滚动窗口，每秒更新一次；不把配置250Hz直接当作测得值。速率表示中枢接纳样本的吞吐，不等于设备时钟或无线链路的独立测量。
2. **合格通道数**：每0.5秒检查最近1.5秒真实EEG，按有版本的软件电气规则检测平线、饱和、RMS、峰峰值和工频。独立于是否已加载分类器；不授予训练或动作资格。
3. **输入缺口比例**：根据同一流从首次观测之后的样本位置，计算 `缺失样本 / (接收样本 + 缺失样本)`。不把首次接入之前的样本位置当作丢失；重复与倒序块不增加已接收数量；新流／配置身份单独统计。卡片单位改为“% 缺口”，不将其冒称原厂无线丢包率。

明确标记的历史补传只影响存储，不刷新接收率或实时模型输入。统计尚未预热时说明等待；短暂迟到不清空数字。持续中断后保留读数并标为上次统计；这些显示值不延长动作有效期。测试覆盖了2秒统计预热、接收抖动、重复块、样本缺口、新流、保留读数及历史隔离。

## 逐通道区域

每个实际EEG通道显示检查结果、RMS和峰峰值；小幅数值使用科学计数显示，避免被格式化成0.0。通道身份沿用实际描述符，辅助列不算进EEG数量。页面按可用宽度排列卡片，只在切换分页或通道身份改变时重建节点，正常轮询只更新文字和状态。

接触阻抗没有测量值时仍为未知，放在统一说明中；不再在每张卡片重复“训练与模型未配置”。软件检查通过不等同于电极接触已验证。

软件观测规则 `gnautilus.electrical.v1`：平线峰峰值不高于0.1uV、绝对幅度达到1000uV、峰峰值超过500uV、去中值RMS超过100uV、48–52Hz工频功率占比超过0.5等情况报告异常。它们是明确的软件粗大异常观测，不是接触阻抗标定，也没有改动当前模型的质量门或权重。
