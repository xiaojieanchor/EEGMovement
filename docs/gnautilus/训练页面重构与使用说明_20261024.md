# 训练页面重构与使用说明

2026-10-24。当前研究主路线为眼动方向控制：不要求四肢想象，区分目标方向、持续注视、回中、眨眼和头动干扰。公开独立EOG结果与个人头皮EEG、VR闭环验收分别呈现。

原页面具备服务器连接、完整记录导入与组合、VR范式设置、训练提交、任务取消/恢复、事件与曲线、模型登记/加载、开发回放及MATLAB数值转换。本轮保留这些入口，重组为五个区域：

| 区域 | 现在可以在哪里完成操作 |
|---|---|
| 总览 | 连接、数据、运行队列、待处理任务、当前模型和最近任务；按实际状态给出下一步入口 |
| 数据与新建训练 | 搜索与来源筛选，分页查看数据；同屏核对训练/开发用途、实际通道、采样率、参考、单位与已审核窗口，再配置算法、窗口、seed和轮数；个人记录导入与组合在页内折叠区 |
| 任务与结果 | 按来源、状态、名称、完整ID搜索；每页10项；选中后查看来源、当前尝试、阶段、模型结果、逐类召回、真实曲线、中文事件摘要与原始JSON；取消和恢复保持明确点击 |
| 模型库 | 按数据身份、名称、算法或原生类别搜索；区分离线分类器和支持实时合同的模型；训练与开发并列，同数据与输入合同比较；任务可以直接定位模型版本 |
| 高级工具 | 私有计算连接、下一次VR范式、外部数值模型导入与MATLAB转换 |

常用路径：选择数据 → 查看用途与输入 → 创建训练 → 查看任务详情 → 在模型库查看产物。训练完成表示产物已导出并登记。加载模型后，推理与动作仍需分别手动启动。准备、UNKNOWN及拒识不改成REST。

已审核的公开派生窗口采用清单中的真实窗口并显示为只读。经典分类器按实际拟合阶段展示，神经网络按提交的epoch绘图。损失与BA分开显示；恢复尝试后不把此前尝试拼到新曲线上。超过500条的事件按服务器游标继续读取。模型比较要求同数据SHA、类别顺序、通道、采样率、窗口和输入合同，不跨数据库排名。

断网或回执过期时保留已读取任务和模型，禁用训练、恢复和加载。数据目录未同步保持未知，不显示为零个已登记数据集。刷新工作台只读，不重载整个页面，也不清空用户输入。
