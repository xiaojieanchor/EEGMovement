# 全量个人导航与眼动状态融合

用户明确本轮方向/通道的差异和相似性应直接使用全部数据。全量描述性统计保留原始角色，但不按角色排除。全量统计选通道、旧JEPA私有训练历史及已反复查看的数据意味着本轮不存在独立测试结论。

## 既有方法与已知结果

原始数据保持32列与250Hz，CH16=Cz、CH19=C5。15个完整试次、22个人工方向眼动事件；无眼动只授权头部0–2秒眼动静止，不等同导航REST。眼动头30候选中验证70%、冻结测试20%，NO_EYE召回0，未上线。导航通道此前只用训练3个严格配对试次排序，BACKWARD训练和RIGHT验证缺一个人工眼动边界；不足以确定四方向最优。新要求用全量可配对试次做更完整的描述性分析。

## 本轮数据和配比

1. 全量通道统计：10个严格配对方向试次，起始眼动结束+1秒至尾部眼动开始−1秒；全部非重叠2秒窗，完整试次等权。统计跨独立试次同方向差异和异方向差异。本轮固定1秒缓冲；原始split保留，但不作为统计筛除条件。
2. 导航监督：上述10方向试次，以及2个本软件明确REST试次。官方REST保留但不混入主适配，以减少此前来源与类别绑定。两个缺边界方向试次不补造强监督，留作未知连续回放。

5. 复用已训练联合JEPA候选的CNN空间层和有状态GRU作为冻结表征，另取因果8–13/13–30Hz多时标功率及通道相关结构。实际训练新导航读出头；不声称本轮重新完成JEPA预训练。保留公开模型及旧JEPA权重哈希。

## 眼动融合状态

复用此前选定人工眼动头，不将其NO_EYE解释为回中。连续3个新100ms周期的高分、充分margin方向事件可改变眼动方向记忆；重复同一burst不重复触发。方向记忆存在时，同向导航门槛较低，其它方向及REST判定门槛较高；但导航证据不足连续2周期仍停止，不能因REST阈值高而无限维持动作。启动至少3个新预测周期，眼动不能单独启动。

相反方向眼动先进入RETURN_OR_SWITCH并撤销旧方向增益；需相反方向导航证据独立越过保守门槛3次才作为方向切换，否则保持无增益的不确定/回中状态。其它方向眼动覆盖旧记忆。低分NO_EYE、眼动未知不冒充回中。QC失败、流身份/采样缺口/换模型/进程恢复清空动作和状态。
