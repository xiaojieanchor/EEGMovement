# 四方向融合的32通道与公共数据

## 候选布局

此表为研究位置顺序，不是已核对的原厂物理端口：8个前额/额区、21个运动相关位置、3个顶区，共32个。

配套[候选位置JSON](/C:/Users/19410/Desktop/EEGMovement/configs/gnautilus_layout32_hybrid_candidate.example.json)默认verified=false、REF/GND及佩戴为空；逐一核对实物后另存正式文件，不能直接勾成已验证。

|---|---|
|01–08|Fp1、Fp2、AF3、AF4、F7、F8、F3、F4|
|09–15|FC5、FC3、FC1、FCz、FC2、FC4、FC6|

前额左右对称布置用于保留眼动辅助的极性及对照；双侧FC/C/CP覆盖双手感觉运动区；Cz及邻近中线兼顾腿部。左右腿在头皮上的表征接近，不预先保证可稳定区分。保留P区作为后部对照，但此布局不是枕叶SSVEP优先布局。

REF/GND按实物接口和电极型号核对。若占用32个可采输入，就必须减配并重新编号，不能把表写成已满足硬件约束。普通头皮前额电极不自动变为眼周EOG；当前方案不安排未经核验的任意眼周接线。

戴Quest前后分别检查前额电极、面罩及顶带压力和接触变化。记录两次佩戴身份、原厂滤波/参考和阻抗；戴上头显后重新检查。采样率用实际设备配置，不沿用旧250Hz。只更改位置文件中的真实映射，不手动篡改已关闭数据来凑32路。

## 数据库优先级与本轮实现边界

前一阶段仅查阅下表原始论文/官方说明，没有下载原始公开大数据。2026-10-23接续已按用户要求向新私有服务器下载官方原始文件，当前完成数、版本、来源、许可及原文件只读核查见[下载与校验记录](../public_download_20261023/公开数据下载清单与状态.md)。未将历史quarantine候选或本次下载自动改为已准入。读取器的合成结构测试、原文件结构核查与正式训练验收分开；每个实际版本仍需核对单位、通道、参考、标签、完整会话分组和来源重叠。个人导航模型默认由个人数据训练，不补假通道或把公共原生任务强行改成导航。

公开库读取入口位于私有服务器 `/datasets/public`；路径限本项目data根，metadata必须有admission=approved、license_receipt、source_version。HaLT须提供channel_names/eeg_column_indices；EEGMMIDB还须run；BCI IV-1须核实physiological_source及native_class_map/task_duration_s；OpenBMI须partition及原生类映射；EEGEyeNet须axes、data_key、target_key、target_semantics、class_column/native_class_map等。此类准入是人工核实后的回执，程序不会因为填了approved就证明许可或原始结构真实。

公开任务在各自合同内训练和评估，未经另行验证不直接与个人32通道记录混合。不同采样、通道、参考、滤波的组合在任务前拒绝，不插值伪造同构数据；需要迁移时另建可审计派生协议。尚无已核查候选可直接替代“左右手腿＋四方向眼动＋长时间无控制＋持续保持”的个人采集。

## 最先做的对照

1. 同一批数据、同一佩戴分组，比较Bandpower、CSP和轻量CNN/GRU；训练及开发分别报告，避免用重叠窗口当独立试次。
2. 中央注视MI、仅眼动、融合各自训练/测试，并跨模式回放。遮掉前额或仅保留前额的分析必须重新训练，不能在已训练模型里随意置零再声称来源隔离。
3. 开发集加入5–10分钟明确无导航意图、自然眨眼/看周围、头动、持续意图、方向切换、主动停止。报告误启动/分钟、覆盖、停止延迟、任务开始到首次正确响应及其分布，不只报告挑出的合格窗口准确率。
4. 独立验收使用未查看的新日期/佩戴，提前锁指标和运行参数。软件回放、厂商示例成绩、开发成绩与真人VR闭环分别保存；若左右腿不可分，先保留眼动映射辅助，再研究更稳的意图语义，不能将失败改标签成成功。
