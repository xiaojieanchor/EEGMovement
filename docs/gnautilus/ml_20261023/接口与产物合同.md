# 接口与产物合同

## 入口分工

本机中枢管理入口保持 `127.0.0.1:8765`；所有写操作要求本地来源及 `X-EEGHub: 1`。服务器仅在 SSH 隧道内接收固定环回 HTTP 请求，独立 bearer 保存在服务器0600文件，公网协议无此转发能力。

|中枢 API|用途|
|---|---|
|GET /api/ml/capabilities|算法可用性；不根据模型文件后缀猜加载器|
|GET /api/ml/local-records|项目内记录身份、关闭状态和实际通道数|
|GET/POST /api/ml/collection-profile|下一次引导/自主采集的实验模式；采集中禁止改变|
|GET /api/ml/datasets|服务器权威数据集|
|POST /api/ml/datasets/import|完整记录核查、SFTP上传、服务器再次核查|
|POST /api/ml/datasets/combine|组合不可变数据集ID；不复制/改写原始标签|
|GET/POST /api/training/jobs|持久任务列表/创建；任意已支持算法都可显示|
|GET /api/training/jobs/{id}|任务与已提交事件|
|GET /api/training/jobs/{id}/events?after={seq}|有序日志游标|
|POST /api/training/jobs/{id}/cancel 或 /resume|取消/显式恢复，保留attempt身份|
|GET /api/models；POST /api/models/refresh、/activate|统一模型目录、刷新、手动加载|
|POST /api/models/import|项目内manifest.json＋weights.npz目录导入|
|POST /api/ml/import-matlab|MAT上传与受控数值转换，首次按离线分类器登记|
|POST /api/ml/replay|选定模型的训练/开发回放，先停止动作；独立test不由此打开|
|GET /api/intent/status；POST /api/intent/start、/stop、/control|实际模型身份、手动推理及独立允许动作|
|GET /api/preparation|新设备软件、服务器、数据、模型、线路分开判断，无旧模型资格门|

### 数据集导入请求

```json
{
  "title": "本人 融合 第一次佩戴",
  "records": [{
    "path": "C:/Users/19410/Desktop/EEGMovement/data/gnautilus/2026-10-23/sessions/实际会话ID",
    "attributes": {
      "subject": "P01", "date": "2026-10-23", "wearing_id": "实际佩戴ID",
      "role": "train", "experiment_mode": "paired", "reference": "与descriptor一致的实际参考",
      "electrical_policy": {"rail_uv": 0, "flat_ptp_uv": 0, "max_rms_uv": 0, "max_line_ratio": 0}
    }
  }]
}
```

上面的0仅表示待填写，**是非法策略，不可直接提交**。不提供冒充实测的默认量程或阈值。实际参考、通道布局、原厂滤波来自采集描述，不能靠请求覆盖。日期/佩戴/角色是操作者据实补录，不回写原始日志。

完整记录四个数据文件大小和SHA与closed清单核对；块偏移、宽度、内容hash、样本数逐块核对。事件映射从源epoch/sample到本地记录行，不能简单拿源样本号直接切原始文件。数据集身份为内容摘要；源同角色重复、跨角色、同佩戴跨角色均拒绝。

### 训练任务请求

```json
{"dataset_id":"实际64位摘要","algorithm":"csp_lda","window_s":1.5,"max_epochs":50,"seed":17,"request_key":"本次操作的唯一请求ID"}
```

相同request_key相同spec返回同任务；修改spec的重复请求拒绝。协议绑定dataset、实际ML及采集解析源码SHA、算法、seed、预算、窗口和分组。生产fit必须处于 `training_authority`，在实际服务器核验GPU；合成测试仅在测试自身mock，不在生产提供跳过开关。独立test源可登记，只有prospective且previously_inspected=false才能声明其身份；当前普通拟合和回放不读test。

状态为 queued → preparing → running → evaluating → exporting → registering → completed，另有waiting_resource/failed/cancelled/interrupted。completed要求model_id已登记。超过200条历史记录不隐藏活动任务；调度和重启恢复独立查询全部未终结任务。经典方法无假epoch。服务器重启把未完成阶段标为interrupted，不盲目复活动作。

## 实时输入和输出

中枢向服务器发送同一原子快照中的descriptor、stream_id、source_epoch、sample_index_end、model_id、generation和尾部样本。样本为 `[EEG通道, 历史点数]` float32数值，经受控JSON传输；n=round(fs×window_s)，不固定250Hz或375点。

服务器再次核对原生来源、已确认布局、EEG通道顺序、采样率、参考、滤波配置、完整窗口、数值及电气策略。中枢还检查窗口全部VALIDATION，不只检查最新块。无该附加通道时有效性保持未知。重复或倒退样本不积累证据；流/epoch变化要求重新手动启动。换模型/配置、数据断流后历史重新预热。

结果带input identity、模型/generation、预测类、五类分数、分支分数、质量和worker_ms。类序严格为REST/FORWARD/BACKWARD/LEFT/RIGHT，外部导入必须与numeric classes `[0,1,2,3,4]` 一致。中枢丢弃迟到、旧generation、跨epoch、旧model及历史回放返回；不会在收到时重置输入年龄。分数语义明确为未经校准的LDA/神经softmax/后融合，不当作速度。

私有服务推理lease为3秒；中枢实时新鲜度为250ms；Quest动作票据仍180ms。这三者用途不同：服务lease仅释放失联的计算状态，不放宽接收端动作有效期。服务自恢复不恢复动作授权。

## 模型目录与数值格式

`models/<model_id>/manifest.json` 绑定：schema=`gnautilus.model.v1`、runtime_schema=`gnautilus.finite_history.v1`、算法、EEG通道顺序、fs、window/hop、input_contract、数值权重SHA、class_labels、质量策略、数据/协议/代码身份、训练/开发指标、评估阶段及runtime_accepted。model_id是去掉自身字段后的规范JSON摘要。

`weights.npz` 仅含数值数组及classes，allow_pickle=false；禁止按后缀反序列化任意对象。文件与解压总量均有限制，加载时核对hash、类序、合同和预测探针。深度网络由受控代码定义，不执行上传网络定义。运行版本不支持的产物明确拒绝。导出后用开发样本核对重新加载预测，任务才可登记。

原生公开任务、少类个人模型及MAT首次转换按离线能力登记，不自动赋予导航含义；已登记、已选择、实际加载、输入相容、效果验收是不同字段。模型库不会因为训练得分低而拒绝技术上兼容的完整导航模型。

### MATLAB数值交换

MAT只接受mean、scale、weight、bias、classes；CSP另需spatial。要求scale正、有限数值，维度通过同一模型预测探针。公式为 `feature -> (feature-mean)/scale -> score=z@weight+bias -> softmax`。CSP滤波、特征、分量顺序必须与本实现完全一致；只给厂商WV不够。

Sidecar JSON必须包含format=`gnautilus.numeric.v1`、algorithm、channels、sampling_rate、window_s、details，并可附class_labels/input_contract/electrical_policy/evaluation_stage。元数据不能替代来源对照。原厂Simulink的滤波器状态、标准化和类序与本实现不一致时，需要先做显式转换与原始预测对照，不假装即插即用。页面的MAT导入不会执行`.p`、MEX、回调或对象，也不会直接赋予实时导航合同。

## 恢复、服务和版本

SQLite WAL持久保存任务、序号日志、模型和选择；数值产物先不可变提交再登记。神经恢复点为 `logs/<job>.latest.<SHA>.pt` 加 `.latest.json` 原子指针，保存模型、优化器、epoch、类别、输入形状、seed及随机状态。旧checkpoint在新指针成功前保留，恢复核对摘要与任务身份。取消与调度认领持有注册表锁，过期队列快照不复活已取消任务。

部署脚本 `scripts/ml_admin.py --deploy` 只管理本项目 `eegmovement-gnautilus.service`，有排队/运行任务或推理时拒绝更新。不可变release、current-release指针和前版本均保留；回滚可停本项目单元、把指针改回已核验release、再启动。新源码不能冒充旧锁定协议续训。检查 `logs/service.log`，不扫描/终止其它项目进程。
