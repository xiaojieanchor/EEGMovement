# A100 自动连接与推理链路验证

2026-10-25。本轮按用户要求关闭真实 EEG 采集端后测试，不要求重新开启设备。

## 结论

本机中枢到新 A100 的 SSH、私有计算服务、凭据恢复、原模型恢复及公开数据离线预测均已实测通过。实时导航推理尚不可用：计算端登记的 127 个模型全部为离线模型，`runtime_model_count=0`。不将公开 EOG 分类器改标为实时导航模型。

当前原模型为 `9ed05505027f1b6141705bf47af4d06f79823fb3af55ab43011258115da7bfc0`，输入为 `EOG_H/EOG_V`、256 Hz，任务为原生眨眼与眼动分类。它不能直接接收 g.Nautilus 的 32 路 EEG，也没有当前导航任务的 REST/UNKNOWN 运行合同。最近已有的采集描述不能替代实际电极、参考、单位、采样配置核验；本轮没有重新测量这些项目。

## 修复

- 自动选择有 IPv4 默认网关的实际上游网卡，排除无网关的热点共享口及 VPN/TUN；存在多个上游时不猜测。为 A100 添加精确 `/32` 校园网主机路由，没有关闭热点或 VPN。路由的接口/下一跳收据在证据目录，网络切换后应重新核查；不声称本轮做过 Windows 整机重启。
- SSH 凭据由当前 Windows 用户的凭据管理器保存，目标绑定主机、端口、用户及固定主机公钥。未写入项目配置或文档。启动可恢复连接；认证或身份异常暂停重试，普通故障按 2–30 秒退避。
- SSH 认证、令牌读取及请求均有超时；令牌读取的截止时间覆盖 SFTP 子系统握手。`/health` 与 `/snapshot` 持续验证服务身份及 GPU UUID。
- 只恢复原先选择的模型；无选择时不按分数挑选。断线缓存不再显示为当前已加载，训练状态和准备报告也不再把最近缓存当作新鲜服务回执。
- 手动断开会暂停自动连接，Windows 凭据保留供下次启动使用。连接代次检查同时拦截已在认证的旧请求及已排队但尚未开始的重连，避免覆盖手动断开。
- 推理页显示连接、加载或离线模型的具体阻塞原因；不能启动的离线模型禁用启动按钮，运行中的停止按钮仍可使用。推理与动作不自动开启。
- 采集端显式填写的热点地址不再被自动发现的 VPN 地址覆盖；留空仍支持自动发现。此修改已纳入本轮独立冻结构建验证。
- 更新两条旧断线测试，使其验证当前“保留会话、清除标签、等待输入”的要求；继续验证断流后的窗口重置和记录关闭清单，不恢复已失效标签，也不补为 REST。

## 当前状态和剩余条件

结束时私有计算连接为 `ready`，原模型实际已加载，推理和动作关闭，网页报告 `offline_model`。用户关闭采集端是本轮已知条件，不作为连接故障。

后续真正启用实时导航仍需：核对实际电极/参考/单位与配置；将满足身份、质量、标签及会话划分要求的真实记录登记；在锁定协议下建立匹配当前输入和导航任务的模型；再完成真实输入和接收端验收。不能通过重命名模型、修改资格标志、重采样猜配或放宽质量门替代这些条件。
