# 眼动分类器与联合导航模型的下一轮诊断

用户已明确授权继续分析、实操优化并加入眼动分类器作真实信号推理。本轮采用既有训练／开发角色，不访问测试EEG，不开启设备或Quest动作，不重新拆分数据。

1. 固定当前127份公开模型、已登记联合模型、来源文件及代码身份，先回放联合／全32路探针／额部方向／原生EOG任务头；区分原生任务语义和私人弱标签，检查置信、类别塌偏和任务初期／保持差异。
2. 按因果电气质量边界统一重置；最低真实支持1.5秒。比较额部有符号低频、多时标全32路谱／相关结构、既有迁移GRU潜表示的轻量正则化读出。全部标准化及读出拟合仅使用训练角色；训练与开发并列。
3. 以锁定的小规模配对方案比较全32路、额部辅助、两者特征融合，以及固定有限增益融合。前／后／左／右仍为联合任务指令标签；无眼位／眨眼真值，不编造分类准确率。
4. 新入口必须通过源／协议／实际入口哈希与指定A100核对，保留安全数组、逐帧回放、真实优化梯度和预算。新增模块为离线研究用途，原服务发布版本及当前所选模型不切换。
5. 文献核心采用已核实高IF期刊的全头皮／在线平滑／人机适配证据，直接EOG方法采用Malta官方说明及其原始论文作为补充。明确任务、参考、采样与眼电电极布局不等价。

完成条件是得到可复核的真实训练与开发结果、负结果、分方向召回、初期／保持表现、固定拒识规则覆盖及来源审计。不能把回放、多个重叠帧或开发选优写成实机／独立试次／独立测试成功。
