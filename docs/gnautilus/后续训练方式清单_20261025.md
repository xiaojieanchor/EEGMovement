2026-10-25。本轮先归档，等补充数据后继续；以下为研究优先级，不是已经证明的效果排名。

| 方式 | 标记 | 当前证据 |
|---|---|---|
| **32路联合融合＋公开权重迁移** | 优先保留为共同底座 | 全通道进入共同分类特征；沿用OpenBMI／EOG兼容权重，实际映射16=Cz、19=C5。准确率仍未达标。 |
| **联合迁移＋JEPA** | 保留实验路线 | 选定第1轮开发BA23.62%，动作接纳覆盖0。未证明比无JEPA更好。 |
| **联合迁移、无JEPA** | 必须保留的对照 | 选定第10轮开发BA23.00%，覆盖0。后续和JEPA用同数据、预算、指标比较。 |
| **事件感知动态多时标** | 优先验证假设 | 新JEPA末轮第10轮因果证据均值使开发BA23.37%→38.15%，但向前召回变成0。可学习事件模块尚未实现。 |
| 只把固定输入历史1.5秒加到8秒 | 降低优先级 | 当前同一权重、同一开发样本，收益很小或没有；有状态模型本身不会每1.5秒清空。 |
| 旧区域独立分类／晚期加分 | 历史对照 | 保留实现与旧结果，暂停作为当前主路线。 |
| 长均值直接接管动作／降阈值换覆盖 | 暂不采用 | 方向召回、切换、回中、停止与误启动尚不合格。 |

**38.15%只是一条事后开发诊断结果。** 同一规则对选定第1轮23.62%→22.99%，对旧第60轮16.56%→7.58%；不能将它写成通用提升。全部回放的提前置信门槛都未触发，实质为随已有历史增长、最长6秒的均值，尚未证明按信号动态早停的收益。此段初次编写时未读取测试EEG；后续测试研究回放见下方新增回执。当前模型选择及手动启动边界不变。

后续补数据时，仍然采集“方向眼动＋对应第一人称导航想象”，不用拆开。优先补每个方向和**同一软件来源的明确REST**的多个完整独立试次；每段保留起始、保持、回中和结束前后。摘戴时记录真实佩戴身份，未标注段仍为UNKNOWN。当前每类只有1个训练试次和1个开发试次，大量重叠窗口不能替代独立重复。

数据界面继续只用一个“个人导航数据集”入口，内部记录来源、质量和方法标记。新增完整采集在使用前分配角色，避免同一原始支持跨集；保留已有测试，承认既有开发已多次查看。后续依次比较联合CE、各方向召回、含拒识表现与覆盖，再验收连续控制及响应／切换／停止延迟。

## 后续冻结眼方向测试回放更新

用户明确要求对已经完成的眼方向头推理并标注范围。本轮0次优化，在A100按完整角色隔离上下文重放既有测试：695次有标签更新，678次就绪、17次预热、0次QC拒绝。旧额部读出／修复额部读出／JEPA额部神经头的含拒绝宏召回分别为26.91%／34.15%／20.16%；修复后的32路加有限额部参照为10.78%。测试早已查看，不计独立新验收，也不据此重新选模或拟合。

修复额部头训练就绪BA89.94%，本次测试35.40%；向下、向右的原任务标签召回均为0。向右143次输入全部就绪且具有6秒历史，全部判为左类，因此不能把该错误归因于未预热。右向起始峰四组水平差分的符号与训练右向一致，但同一个头在测试峰给左类98.4%；按原特征组分解，1.5／3／6秒组将“右−左”logit推向负侧。678次测试预测在第二次提取时逐值复现。

研究优先级仍为：保留32路联合与公开迁移作为待检验底座；修复后的连续上下文作为输入正确性要求；动态多时标／事件与历史方向状态作为预注册对照。不能把这些标成已经获得高准确率或可控制的方法。仅加长历史未解决本批右向／下向错误，动态窗尚无收益验收。测试只作错误分析，不用于窗长、增益或阈值选择。

数据界面仍只有统一个人导航数据集；时间范围候选与确认方向区间保存在内部评估记录，均无眼位真值。报告与16张图的交付索引见同目录《测试眼方向回放与多时标核查_20261025.md》。

## 本次全量个人适配的补充结果

用户明确要求全量通道分析，本轮实际纳入原train/validation/test的10个双眼动配对方向试次，最终拟合另纳入2个软件REST。原角色保留，但这些数据不再提供独立测试结论。

两轮读出头训练记录81/324条候选（含重复seed和重复对照）。当前较好组合为FC6、C2、C4、C6、CPz、CP4、CP6、P4；REST总损失权重50%、四方向各12.5%，频带/相关特征与冻结JEPA潜证据各50%。全量拟合宏召回70.32%，分组头部回放23.20%，不可与此前不同支持范围的38.15%事后诊断直接排名。空间相对功率及保留编码器全32路输入未提高本轮成绩。

已组合旧眼动头与持续方向记忆、相反事件撤销增益、导航独立确认和弱证据停止。固定条件未产生眼动方向触发；动作接纳覆盖仅0.27%，不能称可操控。放宽眼动门槛的最好人工事件匹配也只有4/22，未应用到候选。优先补充联合范式的独立完整试次、完整首尾眼动和软件REST，再锁定眼动事件检测及导航分数尺度；不优先继续无界扫窗口/轮数。完整方法与结果见《全量个人导航与眼动状态融合_20261025.md》及本聊天交付报告。
