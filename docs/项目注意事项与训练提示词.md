# EEGMovement 项目注意事项与训练提示词

**2026-10-19 短暂状态抖动复核**：用户要求修复通道短暂非绿造成的假断连。`training/quality_continuity.py`仅处理已合格通道的厂家无信号状态(-1/3)短闪：软件电气检查始终通过、同一source_epoch、实际样本连续，且200ms/50样本内恢复合格，才生成`quality_resolution`证据。待确认期间暂缓提交对应尾段，不提前授予有效性；确认后以实际决策可用时刻消费，不补造样本，不把真正缺包、幅度/平线/工频/肌电或过期状态变成有效。厂家只允许一次明确标记的重叠窗口快速复查，不当作独立新批次。真实故障保留原恢复确认和滤波重建，CH1/6及至少4路不变。新录制同时保留原始channel_quality与复核事件；旧文件/锁定派生不改。新派生须明确选`online_delayed_status_200ms_v1`并锁来源、延迟语义和新代码；旧`online_known`仍保持原严格语义，不能混称无检测延迟或自动热改旧训练输入。

**2026-10-18 BF16 预热梯度补充优先**：CPU 的“无动静硬门”回归不等于 CUDA 正式训练的监督梯度正常。A100 / PyTorch 2.6.0 已复现旧 ClassBalancedTask 在同一个 autocast 中先 no_grad 预热导致分类头四组纯 CE 梯度为零。下一轮历史预热须禁用该区间的 autocast 权重缓存，监督前向独立建立 cast；冻结头可用原包形状/精度的特征缓存，但仅限完整编码器冻结、core placement、norm/head 可训练。必须同时验证 CE 梯度、loss/更新一致、完整入口失败释放/恢复/导出；不能凭总梯度非零、loss 无 NaN 判定健康。旧运行源不热改、历史失败保留，新源码须重发能力凭据并重新锁协议。见`动静方向梯度核查_20261018.md`及本轮修改报告。

**2026-10-18 动静/方向梯度核查**：当前因果候选是共享CNN/空间/核心GRU/时间编码后直接输出九类联合logits，用真实动作标签的CE监督；动静/轴概率只是输出边缘统计，执行阈值不进入训练图。不得改为依据预测动静的argmax/阈值决定是否计算方向loss。旧fit80同一MLP并行输出1动静＋4方向logits，方向CE按真实`label>0`选样，与预测门分数无关；联合概率乘法仅在推理转换。其CNN按协议冻结，不是被动静门截断。`tests/test_motion_direction_gradients_v1.py`已验证静止logit=30时方向监督仍到全部因果CNN，以及旧头方向loss对动静logit平移不变；测试为合成梯度证据，不是任务准确率。尾层/adapter/head模式不回传全部CNN也是锁定可训练范围，不能误判为架构故障。非线性可微串联本身不自动导致无法反传，真正应防的是硬阈值/argmax、detach/no_grad及错误冻结位置。

**跨设备与历史重放数值证据**：CPU与A100概率不同不能直接推断权重/训练错误。保留失败断言，固定原权重/来源后分别测量最大差、argmax及后端精度；同设备成对干预与原A100复现是不同证据。前缀合并可能提速但改变GRU/注意力舍入，BF16已有约0.00489概率差；不能凭分类未变热替换运行依赖或放松精确恢复。新分块/精度只在新协议、完整入口及梯度/恢复/实际输出验证后采用。未来连续SSL不能每个1-token包重新生成crop时间掩码，否则会全遮；mask计划/RNG/游标应跨包保存并绑定真实源/reset，合成原语测试不代替真实受治理训练。

**2026-10-18 训练日志与拟合防复发**：加权loss与未加权CE必须分开记录；短事件权重18.09曾将CE2.90放大为loss52.41，不能只凭曲线称正常。按端别均衡不等于按类别均衡，须记录实际class/record/event/hop曝光、事件权重、学习率及裁剪前梯度。将按开发选中的参数与最后参数分别完整连续评分，不允许用其中高的训练分数替代所选模型。新训练的当前参数与递归/注意力/卷积缓存世代应一致；是否必须重建历史及收益要由受控对照证明，不能宣称已解决泛化。可选类别/事件均衡以真实训练支持为准，UNKNOWN不参与监督，前缀只含已接收数据；保持QC和至少4路。

**只读评分身份**：保存为report旁的protocol.json可能因JSON格式而与原锁定configs协议字节SHA不同。应核对原锁定文件SHA，并核对副本结构相等，不能放松实际原文件哈希；不得据格式差判断模型无训练。QC合格也可能暂未形成卷积token，描述性特征探针须在看权重前按结构支持锁ID，完整端到端评分仍保留这些预热拒识。中间开发成绩只在真实原子checkpoint提交后展示，不读取正在写的半段预测。

**2026-10-18 最新模型校验规则**：依用户最新明确要求，实时推理与模型动作的手动启动均与是否校验/是否通过解耦。保留真实输入、电气QC、至少4路、来源/模型新鲜度、采集期间暂停执行、失联停止和急停。`hub/model_check_v4.py`仅作可选的固定当前模型性能检查，不拟合偏置、不改变推理输出和控制阈值。每种方向12秒含2秒准备，默认1轮/60秒，可选3或6轮；静息15秒仅覆盖REST。拒识/坏质量数据保留并计入覆盖和含拒识指标，不能仅采高质量时段计算漂亮成绩。完整、取消、失联等结果都保存原始录制、逐帧/QC/事件、模型/配置SHA和报告，并作为已查看/待分配数据进入索引；不自动作为训练数据或独立测试。v2/v3历史实现与评估helpers保留。Quest引导采集v5持续显示动作与倒计时、8/10/12秒任务与心跳，旧原始记录和锁定来源不改写。

## 1. 当前事实与禁止混淆的结论

- 2026-10-18连续训练补充：源/QC/事件元数据必须一致，但不同NumPy/SciPy平台可能产生微小滤波舍入差。保留旧派生及差异报告，在执行环境重建并锁新派生SHA，再保持逐值输入合同；不能通过放松EEG门或宽松吞错替代。每个新执行器须有完整进入/租约/验证/导出/恢复的生成回归；优化块测试、启动PID及预检通过都不是实际EEG优化更新凭据。D05单seed已完成不代表机制收益，seqv2连续监督适配不等于连续JEPA或渐进半监督。

- 当前 70,087,769 参数 fit80：冻结完整 JEPA 编码器，504维融合特征送入约111万参数分类头，无 GRU。当前数值以 `outputs/vr_fit80_report.json` 为准。
- 严格训练回放：1175个合格重叠帧、23个可计分事件，准确率96.09%、BA96.78%。另段开发录制331帧，准确率15.11%、BA12.58%。须同时报告；100ms更新帧不是独立试验或独立佩戴。
- 该差距确认泛化不足，但尚未隔离公共负迁移、冻结表征、头部过拟合、佩戴变化和行为差异各自贡献。不能凭一个差距确定唯一原因。
- 当前扩容主要增加 FFN 隐层宽度，嵌入64维、上下文8层没有同比增加；在线152点、感受野152点、步长128点，每通道只有1个时间 token。预训练长片段的时间粒度不能直接当作在线历史能力。
- 大模型确有公共 SSL 训练实录，不是仅复制参数；历史个人完整编码器监督微调也确实执行过。但二者均不证明核心时序 JEPA 或渐进半监督闭环已实现。
- 通道名称按名义位置及用户提供图理解，不能冒称逐电极实测定位。CH6后续已由用户要求解除禁用，不得沿用“永久损坏”作为当前规则；以当前通道策略和真实质量为准。

## 2. 数据、标签、拆分及质量

1. 原始 JSONL、派生 NPZ、数据 manifest、受试者/录制/摘戴ID、日期与哈希一起留档。重导出、重命名或裁剪同一来源不算新会话。
2. 公共数据按受试者隔离，个人数据优先按完整录制/摘戴/日期隔离；同一事件及其重叠窗、预处理历史、未来目标不得跨集合。时间边界必须追溯到原始样本。
3. REST来自明确静止标签；UNKNOWN、质量拒识、丢包、按钮释放、未标注间歇和组合方向不可静默改成五类里的某一类。
4. 原生任务不同的公开库可共同做无标签 SSL，但不能强制合并为导航监督。统一采样率、通道位置和幅值格式不等于参考/设备/域分布已经对齐。
5. 保留原始质量及50Hz滤后复核结果，不通过放松质量门、补假通道或删难样本来抬分。方向性眼动与电气失效分开处理；50Hz可按现有复核策略滤后纳入，不能将所有坏通道一律视为有效。
6. 必须检查 mask×类别×录制支持、mask-only基线、分支消融与覆盖率。已有诊断发现某些mask缺少前进/左转监督，不能把mask相关性自动当神经任务信息；它是混杂风险，因果贡献仍需实验。

## 3. 公共预训练

- 训练配比可以保留自然比例作为基线，但必须明确记录每域窗口数、更新数、累计裁剪前梯度范数、训练step墙钟时间和实际样本暴露。不得只用文件GB或窗口比例代替梯度占比。
- 验证必须从完整候选manifest中按域→受试者→文件/窗长固定抽取，保存具体pack/窗长/index。禁止某域配额被前几个文件先用完。
- 同时报告逐样本加权批目标、分域宏平均和旧批均值。本次公共训练入口使用域宏平均作为选择loss；总目标含方差/协方差正则，不能命名为纯latent L1。
- 不同batch中正则项依赖批统计，所谓样本加权仍是批目标按样本数加权，不是独立逐窗重新计算的目标。三种口径都要保留。
- 域均衡、近任务子集、逐库移除及显式对齐仍需受控比较，不默认哪一种一定更好。域探针必须按受试者隔离，域可分不等于有害；不同任务不能直接逐类对齐。

## 4. 时序学习及个人迁移

- 2026-10-18 D08准备补充：教师温度的内层校准录制必须整条排除于种子拟合和伪标签池；现有已训练全部六录制的个人权重不能再拿来声明该教师独立校准。必须从公共初始化产生实际种子拟合日志及协议链，不能凭`personal_seed_only=True`等声明放行。当前内层仅21独立种子事件，每轮10%上限为2，不能按重叠帧扩成几百候选。生成CPU/GPU完整engine/事务测试仍不代替受治理实际EEG入口及D08效果实验。

- D05保留四组：冻结特征+监督GRU；编码器与后置GRU监督联合微调；后置GRU+时序潜表示辅助目标；编码器核心GRU+JEPA时序目标。匹配有效历史与预算，分别控制结构、解冻和目标。
- 若GRU只在预训练预测器里、下游弃用状态，不得声称已形成可用核心历史表征。定义教师EMA、detach/截断反传、有效状态传递及质量/缺包/跨录制reset。
- 未来目标的原始起点必须晚于学生所有实际可见原始样本；仅取100ms后的重叠窗不算无泄漏未来预测。滤波、卷积、归一化、注意力和缓存都要验证前缀因果性。
- D08的完整闭环须包含：真实标签种子、独立保留验证、无标签候选池、校准过的质控/一致性/距离证据、逐轮限量及类别配比、低权重伪标签、潜空间受控更新、参照重建，以及权重与可信样本池一起回退。
- 高置信不等于标签可靠，距离近不等于预测正确，远距离也可能是新动作。先验证错误率与风险覆盖关系，再将距离用于门控。高维协方差使用收缩估计或仅训练拟合的降维。
- 伪标签必须保留来源、教师/编码器版本、评分、接纳轮次与审计结果。训练、验证、测试、可信池与审计池不能混用。半监督仍是候选方案，未实施前只允许称“计划”。

## 5. 选模、指标及比较

- 训练拟合允许应用户要求选训练分数，但必须标记 `training_fit`；它不是开发选模、更不是独立验收。fit80不能通过改文件名或改JSON声明变成前瞻性测试流程。
- 固定会话划分、质量/特征/后处理、选择角色及指标。比较增参、解冻或新结构时同时给等更新数与等GPU时间口径；至少3种子用于探索，不能用种子数量代替独立会话数量。
- 主指标：会话BA、宏F1、事件正确率；另列动静、条件方向、原始/平滑结果、覆盖率、切换/停止延迟、自然空闲误启动率。门控接受样本准确率必须配全指令覆盖和正确执行率。
- 不确定性以会话/日期/受试者为单位做配对或分层块bootstrap；会话太少时直接展示原值。不得把每100ms帧当独立样本制造窄置信区间。
- 训练拟合高、SSL loss降、参数非零更新、GPU跑满、PCA聚类变紧，都不能单独证明泛化改善或扩容有效。自然空闲零误触发也不等于风险为零。
- 计算延迟、输入证据历史、软件收到包→模型返回、指令变化→Quest动作必须分开。按压回放快速装载4秒历史不算自然采样响应小于500ms的证据。

固定诊断真实窗口ID、原始样本边界、编码器哈希、特征层、通道mask及窗长。标准化/PCA仅在训练参照拟合一次，后续checkpoint只transform且轴范围一致；逐epoch独立PCA只作附图，不能把坐标旋转当真实迁移。分开448维JEPA与504维融合特征，并同时给高维探针、CKA/谱/有效秩、分域和mask诊断。

新训练应定期保存真实中间checkpoint、best、latest、逐域逐轮日志、逐帧预测与reset、随机状态/优化器、源代码/输入/权重哈希及选模依据。固定保留策略，不能从一个best事后虚构epoch轨迹。本次公共入口已加入每5epoch保存、每阶段保留最近6份诊断编码器；尚未新跑，当前没有由这些新代码产生的曲线。

## 7. 自动检查的使用与边界

入口：`python scripts/check_training_governance.py --protocol <项目内相对路径.json> --entrypoint <训练入口.py>`。复制 `configs/next_training_protocol.template.json` 编写下一轮真实协议；模板故意为draft并缺少哈希，不能通过。

设置项目相对路径：PowerShell `$env:EEGMOVEMENT_TRAINING_PROTOCOL='configs/next_training_protocol.json'`；Linux `export EEGMOVEMENT_TRAINING_PROTOCOL=configs/next_training_protocol.json`。没有指定时默认查找该文件。先通过检查再启动原入口；检查不是要求用户额外审批。

manifest需包含 `split_group` 和 `records`。每条记录包含 `recording/domain/role/source_sha256/files`，`files`是实际输入的`path/sha256`；公共记录补`public/subject`，新独立测试补`date/donning_id/prospective/previously_inspected`。fixed probe JSON包含`recordings`，必须绑定自身哈希。`code_sha256`覆盖实际训练helpers、受保护脚本、政策及当前入口。

自动阻止：无锁定协议、文件/代码哈希变化、分组/原来源/相同派生文件跨角色、公开受试者交叉、旧数据冒充新测试、同次摘戴跨独立测试角色、测试集参与拟合/阈值/诊断调参、错误时间token几何及重叠未来目标、无训练/验证支持、缺指标/预算/中间留档计划、未知或尚未实现的方法能力声明、自动线上提升。

受保护的13个历史实验脚本仍有固定输入和各自的训练行为，因此自动禁止它们声明前瞻性测试；fit80还被限制为冻结单窗的训练拟合。要开展真正新会话测试，必须迁移实际输入/选择/测试读取逻辑并验证，不能只填新manifest。普通数值fixture测试不接触真实EEG，在测试内显式隔离，不提供生产跳过开关。

**检查能约束数据身份和协议中的明显违规，不能证明声明都已由算法实际执行，也不能保证下一轮准确率提升。** 实施者还必须核对实际脚本读取的数据、seed、预算、模型可训练部分、伪标签算法与协议一致。D05/D08、校准曲线和独立任务收益必须有实际实验结果；不得把通过preflight当作完成这些实验。

以上历史核对时的改动最初仅在本地。2026-10-17后续已同步v2入口并启动后台准备/首轮实验队列；以当前协议、远端进度和下述实施记录为准。直接上服务器操作前必须同步并核验同一源码/协议哈希，不得将旧副本视为已受新检查保护。线上权重尚未更换。

## 8. v2重构的强制规则与当前边界

- 2026-10-18恢复补充：监督正则涉及的可训练参数必须在DDP实际forward图内；不能在find_unused_parameters标记后于外部访问mask_token等参数。完整恢复入口为`staging/causal_resume_v6/train.py`，必须用`scripts/build_recoverable_protocol.py`锁`atomic_latest_v6`及实际staged helpers。原v2无加载完整恢复能力。真实通过凭据仅`real-recovery-v8/report.json`；v6原passed已被validity-audit撤销，v7断言失败，不能重用。
- 外部故障验证必须检查实际GPU子工作进程，而不只是launcher进程组；torchrun子进程可能有独立session。先核验父子关系、PID创建时间和命令，再冻结全部工作进程、核验持久化检查点、终止并回收；后续报告的restored_step和独立attempt必须与提交步数吻合。返回已有完成报告、从零重跑、原工作进程仍运行均不能算恢复。不得只看report.state=passed。
- 在线一致信号准备必须记录FIR输出原始支持终点及判断可用终点，不重复追加mask切换重建的旧缓存。固定四秒共同mask与动态在线mask支持不同，逐录制报告实际使用量；不得静默丢无支持录制或把UNKNOWN补REST。共享滤波函数不能代替IIR/anchor/FIR相位与神经历史等价验证。当前可微流原语未成为实际受治理EEG训练入口，不能据此宣称序列训练完成。

- 未来目标必须记录实际参与更新的batch交集、各域/horizon支持、目标变化及训练角色常量基线。BETA无未来支持不能虚报有未来收益；final2000的teacher/predictors不能冒称best1200。旧resume缺step须如实保留配对限制，不能补造元数据。500ms独立重置的teacher上下文与学生2s过渡排除不同，是否影响效果需实际消融；不因低loss或小probe低方差直接宣称全编码器塌缩。
- D05比较GRU放置时共同E、GRU初始化、参数量、冻结范围、历史和预算必须实际匹配。已核心GRU公共训练的网络去掉GRU不能冒充公共none底模。共享预处理代码不等于初始滤波/anchor/FIR相位一致，须验证独立crop与在线状态，不能回填未来历史。

- 固定probe须在实际协议编译时绑定每个crop的原始范围、事件、seed、QC及评分token，并在执行时匹配；声明录制列表不能替代真实样本锁定。原标签与事件选择mask分别保存，计分工具必须消费scoring_mask；旧审计若不支持必须拒绝，不能把同crop其他类别误计进选定事件。训练参照潜特征缩放仅拟合预锁定train部分，保持初始化函数与导出折叠一致，效果须做对照。v2g五组是单seed筛选，不冒充完整因子或三seed确认。

- 稀疏监督不能依赖固定80次随机拒采赌命中。个人片段应从真实连续、全片段至少4路共同合格且预热后有已知监督的起点索引抽取，保存支持数量和哈希。没有支持必须明确失败，不能补REST、降质量、跨缺包或用padding救场。索引采样策略要进入实际协议；已完成公共checkpoint按SHA复用，不因个人采样器修复重跑同一公共预算。

- 私人验证probe必须检查实际类别支持，使用类/录制/事件分层覆盖所有物理可支持类别。缺基础类时不得称完整五类BA或用来决定主模型扩容；先区分真实无连续支持与抽样漏类。2026-10-18曾有原数据962个合格前进起点而固定随机probe没有前进的情况。不可热换正在运行实验的验证集抬分；另锁协议、保留旧结果，并配完整因果重放。

- 不得在编译、队列和每个DDP进程重复全量读取未变数据。使用实际SHA计算建立、文件身份/修改时间/签名绑定的验证索引；数据变化必须重读，代码/协议/角色每次仍查，不能手填预期SHA冒充已核验。当前索引只在POSIX内容变更时钟可用时复用，Windows保守完整读取。

- 双卡集体通信的每个操作数必须显式固定dtype和shape，禁止依赖Python整数/小数的自动类型推断。2026-10-18曾因4秒与2.5秒混合抽样导致时长同步类型不一致、输入几何错误退出；回归必须包含跨rank不同局部时长、可变token数及不同未来目标支持，不能仅用相同512点合成输入。
- 训练进程失败后保留最后进度，但必须明确“已停止”。旧JSONL存在、loss有值或队列曾启动都不能证明任务正在运行；新实验采用新身份，保留失败来源和日志。

- 正常推理由后端校验本次佩戴校准。只有用户点击才启动；未校准正常启动或直接启用动作必须返回`calibration_required`。重启、换模型/配置、用户重新佩戴会撤销；普通Socket重试不撤销。设备真实摘戴无法自动可靠识别，必须保留“我已重新佩戴”。
- Quest应用启动须先确认撤销旧授权，Android的XR尚未就绪也不得绕过。门禁必须在接收器实际Accept/Step执行路径消费，状态遥测不能代替执行门；开关门均清除旧排队包/票据，且保留用户急停。录制间相同事件号必须以recording隔离后再做事件均衡。
- 校准显示由独占展示租约确认；页面隐藏、头显暂停、取消、A键退出或急停后不能继续解锁。20秒静止、75秒适配、25秒独立功能检查；检查标签不参与拟合。至少4路、覆盖80%、各适配类8秒、五检查事件至少4对且静止不动作。失败记录不能删掉后只报告成功佩戴。
- 旧fit80仅施加小幅输出偏置；v2支持基线阶段拟合的有界增益。不允许把旧模型说成支持本次编码器归一化。功能检查不是独立准确率，也不是概率可靠性证明。
- 质量结果同时保存样本支持范围与`available_sample_index_end`。因果重放只能在结论实际可用后使用；未知质量不回填成绿。断路、平线、饱和等必须排除，50Hz只有滤后复核通过才纳入。CH6恢复常规判断。
- 共享预处理为训练和推理提供同一因果滤波实现；前端展示滤波不作为模型第二输入源。单路异常局部隔离，神经状态从实际合格缓存重建；不得为消除预热提示放松质量门或补造时间。
- v2实际模型为5,609,177 / 34,833,881 / 78,201,049参数，核心GRU参与EMA潜目标。通过数值测试只说明代码能力；D05四组机制对照、未来目标收益、D08完整渐进半监督和新佩戴收益仍需实际完成。
- 九类联合分布必须产生真实两轴边缘概率；五类旧模型只能注明旧式轴融合。组合方向尚未单独合格时禁止v2组合执行。中枢唯一负责概率平滑/确认，Quest负责签名、时效、能力协商、看门狗及物理速度斜坡。
- 诊断回放与实时输入互斥，按住发送训练原始EEG、松开停止，循环换epoch。回放不录入个人采集、不授予校准、不伪造概率；驱动Quest需显式启用诊断动作，并记录TRAINING_TEST来源。加载4秒旧历史的速度不能当生理意图响应延迟。
- 当前历史资料不足以证明跨佩戴合格。上线门槛除数值、覆盖和真实Quest延迟外，还要求预锁定的新佩戴证据、至少两个不同佩戴、基线归一化及适配/检查/冻结/评分边界。未校准的影子轨道、历史高分或近似离线前缀检查不能授予上线资格。
- `training/evaluation_v2.py`的离线前缀评分原语仍须与新采集的实际展示、暂停、基线增益和一秒过渡规则逐项对齐后，才能声明`operational_calibration_equivalent`。当前不应手填该声明让历史数据过门。
- 新训练的每步日志来自真实优化更新；原始分片与逐文件SHA检查属于训练前阶段，应显示实际文件进度，不把等待称为epoch。正在运行的训练不得热覆盖其Python依赖；更新队列只允许在尚无真实trainer时进行。
- 新采集安排见`configs/personal_collection_next.json`：5天8次佩戴、约120分钟墙钟、至少90分钟有效目标。自然空闲观察另外累计至少15分钟，必要时追加，不用大量重叠帧压低误启动不确定性。
